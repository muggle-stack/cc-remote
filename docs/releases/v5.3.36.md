# cc-remote v5.3.36

## 中文

本次更新统一应用升级入口，优化 Claude 模型回退交互，并修复 Codex 任务完成后的图片回看。

- 点击当前设备的更新按钮，可依次升级服务器、当前设备和网页。更新任务持久保存，关闭页面、服务器重启及设备重连后可继续查看进度和恢复原任务。
- 设备离线或不支持应用内更新时，可单独更新服务器和网页。等待服务器更新期间可取消后续设备升级，已启动的共享服务器任务继续执行。
- 受管理安装自动配置更新权限。旧安装可通过一次系统认证继续，认证后重新读取服务器与设备能力，兼容源码和受管理安装共存。
- GitHub 匿名 API 达到限额时，通过稳定版重定向查询版本，并缓存共享查询结果。
- Claude 模型回退弹窗使用普通提问卡片的布局，手机端三个操作保持同一行，保留同意、拒绝、编辑提问和自动切换偏好。消息流移除重复的回退提示。
- Codex 批量工具查看的图片在任务完成后仍可预览和放大，支持刷新、缓存回看和超长轮次分页。历史预览从原生记录恢复当时的图片字节，通过现有鉴权接口按需加载。

发布通信协议为 **v94**，Claude Agent SDK 版本为 **0.2.174**。

```sh
cc-remote update --check --version 5.3.36
cc-remote update --version 5.3.36
```

查看安装与升级步骤。[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.36/docs/installation.md)

## English

This release unifies application upgrades, refines Claude model fallback dialogs and restores image previews after Codex tasks finish.

- Start the server, current device and Web upgrade from one action. Persisted jobs support progress checks and recovery after page closure, server restarts and device reconnection.
- Update the server and Web independently when the selected device is offline or cannot update in the application. Cancel a queued device upgrade while its already-started shared server job continues.
- Managed installations configure update permissions automatically. Existing installations can continue after administrator authentication, with fresh capability checks for managed and source installations.
- Use the stable-release redirect when GitHub's anonymous API is rate limited and cache shared version queries.
- Align Claude model fallback dialogs with ordinary question cards, keep the three actions in one row on phones and retain accept, reject, edit and automatic-switch preferences. Remove duplicate fallback notices from the transcript.
- Restore Codex batch-tool image previews in completed history, after reload and in long-turn pages. Recover original image bytes from native records and load them on demand through the existing authenticated image route.

Wire protocol is **v94**. Claude Agent SDK version is **0.2.174**.

The commands above select this release explicitly. Follow the installation guide for setup and upgrades. [Installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.36/docs/installation_en.md)
