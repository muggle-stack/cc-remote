# cc-remote v4.0.9

## 中文

v4.0.9 改善手机侧栏开合与滑动体验，修复打开侧栏后立即滑动列表时的惯性中断。
产品版本 **4.0.9**，通信协议保持 **v74**，Claude Agent SDK 保持 **0.2.157**。

### 本次更新

- **侧栏响应**：减少导航时正文重渲染与 Markdown 重复解析，改善会话输出期间的
  手势响应；保留轻扫松手时的速度，支持快速反复打开、关闭和中途反向拖动。
- **渐进动效**：淡入淡出、正文模糊与圆角随拖动进度变化，适配明暗主题，避免
  起手立即切换到完全展开的效果。
- **列表惯性**：保持手机滚动图层稳定，侧栏开启动画不再因纵向触摸而暂停、重启；
  取消被滚动或触摸取消事件打断的长按操作，避免列表滑动途中弹出菜单。
- **弹窗定位**：图片、Mermaid 预览和粘贴编辑弹窗保持相对整个视口定位。

**已知限制**：iPhone PWA 实测确认打开后立即滑动的惯性中断已解决，开合明显改善；
起手仍可能出现轻微抖动，尚未完全消除。

### 升级

从 v4.0.8 升级时协议不变。安装器管理的部署在独立终端运行：

```bash
cc-remote update --version 4.0.9
```

设备更新先核对配对 Relay；已是目标版本时只更新本机。其他设备逐一更新后，
重新加载 Web/PWA。更早且协议不兼容的版本仍需协调升级 Relay、Web 和全部 Wrapper，
并按[安装与升级](https://github.com/muggle-stack/cc-remote/blob/v4.0.9/docs/installation.md)
使用 `--allow-protocol-change`。源码与容器部署继续使用各自的安装流程。

本次修复不要求重启独立 Claude 会话服务。发布包包含 Linux Relay、Linux/macOS
Wrapper 的 x86_64 与 arm64 版本，Relay 包内含 Web；不包含 Desktop 或实验 DSH 安装包。

## English

v4.0.9 improves mobile sidebar navigation and fixes interrupted session-list momentum
when scrolling immediately after opening the drawer. Product version **4.0.9**,
wire protocol **v74**, Claude Agent SDK **0.2.157**.

- Reduce conversation rendering and repeated Markdown parsing during navigation
  and streaming. Preserve release velocity, repeated swipes and gesture reversals.
- Make fade, blur and rounded corners follow drag progress in both themes.
- Keep mobile scroll layers stable and leave the opening animation undisturbed
  by vertical touches. Cancel abandoned long presses during native scrolling.
- Preserve viewport positioning for image/Mermaid previews and paste editors.

**Known limitation:** iPhone PWA testing confirms that immediate scrolling no longer
loses momentum and opening/closing is substantially smoother. A small first-drag
jitter can still occur.

### Upgrade

The wire protocol is unchanged from v4.0.8. In an independent terminal, run
`cc-remote update --version 4.0.9` for installer-managed deployments. Device updates
verify the paired Relay first and skip its upgrade when already current. Update
other devices individually, then reload Web/PWA. Older incompatible protocol versions
still require a coordinated Relay/Web/Wrapper upgrade with `--allow-protocol-change`;
see the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v4.0.9/docs/installation_en.md).
Source and container deployments retain their existing procedures.

These fixes do not require restarting the independent Claude session service.
Assets include Linux Relay and Linux/macOS Wrapper packages for x86_64 and arm64,
with Web bundled in Relay. Desktop and experimental DSH installers are not included.
