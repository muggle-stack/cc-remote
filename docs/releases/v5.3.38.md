# cc-remote v5.3.38

## 中文

本次更新修复 Claude 侧边聊天的压缩状态，并完善 DSH 移动端终端操作。

- Claude 在侧聊补充输入或中间响应结束后继续输出时，及时收起已完成的压缩提示。
- 压缩状态与原生响应身份保持关联，并发后台任务独立处理，保留补充指令的运行状态。
- 终端空闲且位于底部时，上滑调出历史命令，在空白区域按住后右滑接受 shell 补全建议。
- 长按终端文字可选择内容，新增复制和粘贴按钮。浏览器无法直接访问剪贴板时，可通过文本面板完成操作。
- 命令运行、选择文字和全屏终端应用期间保留对应操作，关闭或重新连接终端时清理手势与剪贴板状态。

发布通信协议为 **v94**，Claude Agent SDK 版本为 **0.2.174**。

```sh
cc-remote update --check --version 5.3.38
cc-remote update --version 5.3.38
```

查看安装与升级步骤。[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.38/docs/installation.md)

## English

This release fixes Claude side-chat compaction status and improves mobile DSH terminal interaction.

- Clear completed compaction indicators when Claude continues through a side-chat input or an intermediate response boundary.
- Associate compaction with its native response, handle concurrent background tasks independently and preserve accepted follow-up input state.
- Swipe up at an idle terminal prompt at the bottom of the screen to recall command history. Hold a blank area and swipe right to accept shell suggestions.
- Long-press terminal text to select it and use the new copy and paste buttons. A text sheet supports browsers with restricted clipboard access.
- Preserve scrolling and selection during active commands and full-screen terminal applications, and clean up gesture and clipboard state when closing or reconnecting.

Wire protocol is **v94**. Claude Agent SDK version is **0.2.174**.

The commands above select this release explicitly. Follow the installation guide for setup and upgrades. [Installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.38/docs/installation_en.md)
