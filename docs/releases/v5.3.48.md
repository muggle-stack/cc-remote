# cc-remote v5.3.48

## 中文

本次兼容版使用 Claude Agent SDK **0.2.174** 和通信协议 **v97**，恢复旧版设备的应用内升级路径。

- 使用 SDK 0.2.174 的设备（包括 v5.3.46）可以直接通过应用内更新安装本版。已经安装 SDK 0.2.184 的 Wrapper 可通过后续同 SDK 的版本接入迁移流程。
- 后续更换 SDK 且本地服务协议一致时，安装器等待运行中的轮次、后台任务、回调、队列和待确认日志收尾，再同时切换受管理的 Claude 服务与 Wrapper。切换失败时恢复上一套服务。
- 空闲驻留的 Claude、Codex 和 DSH 会话通过升级检查。Claude 会话可在升级后按原 ID 继续。

使用 v5.3.46 的设备可在应用内选择更新。安装步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.48/docs/installation.md)。

## English

This compatibility release uses Claude Agent SDK **0.2.174** and wire protocol **v97**. It restores in-app upgrades for devices on the previous SDK.

- Devices on SDK 0.2.174, including v5.3.46, can install this release through the in-app updater. Wrappers already on SDK 0.2.184 can adopt the migration flow through a later release using that SDK.
- On a later SDK change with the same local service protocol, the installer waits for active turns, background work, callbacks, queued inputs and outstanding acknowledgments. It then switches the managed Claude service and Wrapper together and restores the previous pair on activation failure.
- Idle Claude, Codex and DSH sessions pass update admission. Claude sessions can resume under their original IDs.

See the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.48/docs/installation_en.md) for setup and upgrades.
