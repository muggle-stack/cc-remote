# cc-remote v5.3.57

## 中文

- Codex 后台任务回执在发送前断线，或收到确认未受理的过载、关停响应时，会自动补投已保存的结果。
- 发送确认丢失后，worker 会在原会话按 `task_id` 核对回执，找到后继续跟踪已有的 Codex 轮次。恢复过程无需用户发消息或重跑原命令。
- 无法确认受理的回执可继续通过 `task_result` 取回结果。

本版使用通信协议 v98。更新步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.57/docs/installation.md)。

## English

- Codex background task receipts retry from saved results after a pre-submission disconnect, native overload, or a shutdown response confirming non-admission.
- After a lost acknowledgment, the worker looks for the exact `task_id` in the original thread and tracks the existing Codex turn when the receipt is found. Recovery needs no new user message or command execution.
- Results with unconfirmed receipts remain available through `task_result`.

This release uses wire protocol v98. See the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.57/docs/installation_en.md) for update instructions.
