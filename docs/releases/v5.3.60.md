# cc-remote v5.3.60

## 中文

- 修复新版 macOS Codex App 从 Codex Shared 启动时的 403。Default 和 Stack 入口都能连接各自的共享 daemon。
- Codex 的浏览器完成标记在过程时间线中显示为已完成状态，实时消息和历史回放一致。
- Codex 侧边聊天恢复显示各自的后台任务，包括启动参数和任务完成状态。

本版使用通信协议 v98。更新步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.60/docs/installation.md)。

## English

- Fix the 403 when launching the updated macOS Codex App through Codex Shared. The Default and Stack launchers connect to their selected shared daemons.
- Codex browser completions appear as finished activities in both live chat and restored history.
- Codex side chats show their own background tasks, including launch parameters and completion status.

This release uses wire protocol v98. See the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.60/docs/installation_en.md) for update instructions.
