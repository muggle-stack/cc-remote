# cc-remote v5.3.29

## 中文

本次更新统一 Codex 异步提问交互，补齐提问通知，并完善历史记录、多端回答与键盘操作。

- 提问采用共享圆角弹窗，显示 Codex 图标和“Codex 想确认一下”，适配桌面与手机。
- 每题独立保存输入和选项，可通过“上一题”“下一题”选择回答顺序。关闭按钮忽略当前问题，“稍后回答”收起弹窗并保存草稿。
- 回答按原生接受结果确认，已提交的用户消息保留“查看问题”入口，方便回溯问题与回答。
- 历史分页中的问题与实时问题一同进入待回答清单。识别到其他客户端已回答某题后，清理该题的本地草稿。
- 修复空白草稿、仅保存滚动位置及已回答问题的残留草稿导致的页面更新阻塞。输入或清空自定义回答后，可通过键盘重新进入选项组并选择。
- Codex 异步提问接入 Web Push 和鸿蒙推送，遵循现有隐私设置，并对实时事件按设备去重。

发布通信协议为 **v94**，Claude Agent SDK 版本为 **0.2.174**。Relay 与 Web 配套升级，Wrapper 通过独立维护通道逐台升级。较早更新器首次跨协议升级时，按安装说明使用新版 Release 安装脚本或 `--allow-protocol-change`。

```sh
cc-remote update --check --version 5.3.29
cc-remote update --version 5.3.29
```

查看安装与升级步骤。[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.29/docs/installation.md)

## English

This update unifies Codex asynchronous questions, adds live question notifications and improves history, multi-client answers and keyboard navigation.

- Use the shared rounded dialog with the Codex icon and “Codex 想确认一下” heading on desktop and mobile.
- Keep independent input and choices for each question, with previous/next navigation. Closing dismisses the current question, while postponing collapses the editor and saves its draft.
- Confirm submitted answers through native acceptance and retain the question disclosure in the user's reply for provenance.
- Include loaded historical questions alongside live questions. Recognizing an answer from another client retires the matching local draft.
- Reconcile empty drafts, retained scroll positions and answered drafts with the page-update guard. Keep answer options keyboard-accessible after custom text is entered, cleared or restored.
- Deliver live Codex question notifications through Web Push and Harmony Push with existing privacy modes and device-scoped deduplication.

Wire protocol is **v94**. Claude Agent SDK version is **0.2.174**. Upgrade Relay and Web together, then upgrade Wrappers individually through maintenance. Older updaters can follow the installation guide for a first cross-protocol upgrade with the verified new installer or `--allow-protocol-change`.

The commands above select this release explicitly. Follow the installation guide for setup and upgrades. [Installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.29/docs/installation_en.md)
