# cc-remote v5.3.13

## 中文

优化文件预览标题栏，并修复工作状态提示的配色和动画对齐。

- 文件名使用随文字宽度收紧的圆角胶囊，长文件名仍省略显示，下载、展开和向右收起按钮保持靠右。
- 完整文件路径和“重新读取”收进文件名弹层，支持点击外部、切换焦点和 Escape 关闭；预览内容和交互状态保持不变。
- HTML、Markdown 和 Mermaid 的预览／源码切换单独排列，图片等媒体保持单行标题栏；返回 Artifacts 或文件目录的入口整合到标题栏。
- 文件读取期间提前保留下载及编辑按钮的位置，准备完成后启用，避免按钮突然出现导致布局跳动；失败、等待授权或文件被截断时不能下载，重新读取会释放旧下载链接。
- Claude、Codex 和 DeepSeek 的流光词使用各自的主题强调色，并跟随自定义主题。
- 修复 Claude 工作动画在非整数页面缩放下逐帧左漂、周期结束又跳回的问题。保留原有图案、呼吸节奏和完成后的点击回放。

通信协议保持 **v90**，Claude Agent SDK 保持 **0.2.174**。本次 cc-remote 更新不会替换或重启原生 DSH、Codex 或独立 Claude 会话服务。

```sh
cc-remote update --check --version 5.3.13
cc-remote update --version 5.3.13
```

更新器先验证并升级已配对的 Relay，再更新当前设备；其他设备需各自更新。更新前等待进程内会话、侧聊和排队消息完成，更新后重新加载 Web/PWA。

发布继续包含鸿蒙 **0.1.0-preview.6** 未签名 HAP、构建元数据和独立校验文件，沿用已验证的原生构建；已安装 preview.6 无需重装。HAP 需要使用自己的开发者及设备 Profile 签名。本次没有新的 Desktop 安装包。

## English

Refine file-preview headers and correct working-indicator colors and alignment.

- Size rounded filename controls to their text, truncate long names, and keep download, expand and right-chevron collapse actions aligned to the right.
- Move the full file path and reload action into a filename popover that closes on outside interaction, focus changes or Escape, preserving the preview and its interactive state.
- Separate HTML, Markdown and Mermaid preview/source controls from navigation. Keep media headers on one row and integrate return navigation for Artifacts and file directories.
- Reserve download and editing controls while reading files, enabling them when ready without shifting the layout. Disable downloads after errors, while authorization is pending or when content is truncated, and revoke stale download URLs on reload.
- Use each harness’s theme accent for Claude, Codex and DeepSeek shimmer words, including customized themes.
- Fix cumulative leftward drift and cycle-reset jumps in Claude’s running animation at fractional page zoom. Preserve its original shapes, breathing cadence and completed-click replay.

Wire protocol **v90** and Claude Agent SDK **0.2.174** are unchanged. Updating cc-remote does not replace or restart native DSH, Codex or the independent Claude session service.

```sh
cc-remote update --check --version 5.3.13
cc-remote update --version 5.3.13
```

The updater verifies and upgrades the paired Relay before the current device. Update other devices individually, let in-process sessions, side chats and queued messages finish first, and reload Web/PWA afterwards.

Assets retain the verified HarmonyOS **0.1.0-preview.6** unsigned HAP, native-build metadata and separate checksums. Existing preview.6 users need no native reinstall; the HAP requires your own developer/device signing profile. No new Desktop installer is included.
