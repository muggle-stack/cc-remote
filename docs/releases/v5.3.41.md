# cc-remote v5.3.41

## 中文

本次更新修复 DSH 终端历史命令连续跳动，以及 iOS 普通聊天输入框在键盘上方留下多余空白的问题。

- 终端长按滑动一次发送一个方向键。需要再选一条历史命令时，松手后重新滑动，持续按住或手指抖动都会保持当前选择。
- 方向提示移除连发速度，继续支持长按选字、选区手柄、复制粘贴和双击 Tab。
- 普通聊天输入区跟随 iOS 键盘弹出时的页面偏移，减少输入栏被额外推高造成的留白，收起键盘后恢复布局。
- 补充长按手势、连续页面偏移、中文输入和键盘收起恢复的浏览器回归检查。

iPhone 真实软键盘的效果仍待设备验收。iOS 浏览器的上下输入框导航和完成栏继续由系统控制。

发布通信协议为 **v94**，Claude Agent SDK 版本为 **0.2.174**。

```sh
cc-remote update --check --version 5.3.41
cc-remote update --version 5.3.41
```

查看安装与升级步骤。[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.41/docs/installation.md)

## English

This release fixes DSH terminal gestures that advance through command history repeatedly and excess space above the iOS keyboard in the chat composer.

- Send one arrow key per long-press drag. Release and start another gesture to select the next history entry. Holding still or changing direction within the same gesture preserves the selection.
- Remove repeat-speed feedback while preserving text selection, selection handles, clipboard controls and double-tap Tab.
- Follow document panning when iOS opens the keyboard so the chat composer stays aligned with the visible area, and restore the layout when the keyboard closes.
- Add browser regression coverage for held gestures, repeated document panning, Chinese input and keyboard dismissal.

Physical-iPhone software keyboard acceptance is still pending. The browser's previous/next/done keyboard accessory remains system-controlled.

Wire protocol is **v94**. Claude Agent SDK version is **0.2.174**.

The commands above select this release explicitly. Follow the installation guide for setup and upgrades. [Installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.41/docs/installation_en.md)
