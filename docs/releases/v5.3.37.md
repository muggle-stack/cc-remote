# cc-remote v5.3.37

## 中文

本次更新修复 Linux 定时清理服务的启动问题，并完善 systemd 服务依赖解析。

- 正确生成清理服务的工作目录配置，支持包含空格和特殊字符的路径。
- 安装清理任务时校验 systemd unit，并确认定时器已经激活，让延迟清理能够按计划重试。
- 按配置节识别服务描述、文档和日历表达式，避免将其中的标点或变量形式误判为运行时路径。
- 环境文件中的同名变量仍会检查路径和符号链接依赖，保护正在使用的旧版本。
- 增加真实 systemd 语法校验及服务依赖保护的回归测试。

发布通信协议为 **v94**，Claude Agent SDK 版本为 **0.2.174**。

```sh
cc-remote update --check --version 5.3.37
cc-remote update --version 5.3.37
```

查看安装与升级步骤。[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.37/docs/installation.md)

## English

This release repairs Linux scheduled cleanup and refines systemd service dependency parsing.

- Generate a valid working-directory setting for the cleanup service, including paths with spaces and special characters.
- Validate the generated systemd units and confirm timer activation so deferred cleanup can retry on schedule.
- Recognize descriptions, documentation and calendar expressions within their configuration sections to avoid treating their punctuation or specifiers as runtime paths.
- Check paths and symlink dependencies in environment variables with matching names to protect releases that remain in use.
- Add native systemd syntax checks and service dependency regression tests.

Wire protocol is **v94**. Claude Agent SDK version is **0.2.174**.

The commands above select this release explicitly. Follow the installation guide for setup and upgrades. [Installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.37/docs/installation_en.md)
