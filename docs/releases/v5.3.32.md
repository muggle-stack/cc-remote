# cc-remote v5.3.32

## 中文

本次更新完善部署文件的延迟清理与暂存回收，优化首次打开 Codex 会话列表的响应。

- 安装器注册 systemd 定时任务或 macOS LaunchAgent，每五分钟在安装锁内重试延迟清理，重新核对进程引用、服务健康、连接和原生配置。
- 新部署暂存绑定到激活事务及原始目录身份，验收通过后进入现有清理事务，断连后可继续完成收尾。
- 临时服务输入消失时重新完整发现依赖，支持标准 systemd 目录指令，并按完整模板、所有者和权限验证安装器生成的服务定义。
- macOS 可通过 `cc-remote cleanup --authorize-system-scan` 授权固定的系统服务 plist 只读助手，清理由安装用户执行。
- 更新界面区分运行时依赖、等待重连、权限不足等清理原因，后续清理完成时自动刷新更新结果。
- Codex 优先返回原生索引会话，再后台补全 CLI 历史，通过刷新通知更新列表，并保护失败账号缓存及并发读取顺序。

发布通信协议为 **v94**，Claude Agent SDK 版本为 **0.2.174**。Relay 与 Web 配套升级，Wrapper 通过独立维护通道逐台升级。

```sh
cc-remote update --check --version 5.3.32
cc-remote update --version 5.3.32
```

查看安装与升级步骤。[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.32/docs/installation.md)

## English

This update recovers deferred deployment cleanup, retires verified staging workspaces, and improves the initial Codex session-list response.

- Install a systemd timer or macOS LaunchAgent to retry deferred cleanup every five minutes under the install lock, with fresh process, service, connection and native configuration checks.
- Bind new deployment staging to its activation transaction and original directory identity, then retire it through the existing cleanup transaction after verified acceptance, including recovery after a disconnected caller.
- Rediscover dependencies when transient service inputs disappear, resolve standard systemd directory directives, and validate installer-generated definitions against their full templates, owners and modes.
- Authorize a fixed, read-only macOS system plist helper with `cc-remote cleanup --authorize-system-scan`, keeping cleanup under the installation user.
- Show specific cleanup reasons such as live runtime dependencies, pending reconnects and missing permissions, and refresh completed update receipts after maintenance succeeds.
- Return native indexed Codex sessions before background CLI history reconciliation, notify clients when the catalog changes, and preserve failed-profile caches and concurrent-read ordering.

Wire protocol is **v94**. Claude Agent SDK version is **0.2.174**. Upgrade Relay and Web together, then upgrade Wrappers individually through maintenance.

The commands above select this release explicitly. Follow the installation guide for setup and upgrades. [Installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.32/docs/installation_en.md)
