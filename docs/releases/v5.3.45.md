# cc-remote v5.3.45

## 中文

本次更新新增 PPTX 内嵌预览，可在手机与电脑上直接查看会话生成的幻灯片。

- 支持翻页、缩略图、缩放和下载原文件。手机端采用连续纵向阅读，底部操作栏便于单手使用。
- 幻灯片卡片、缩略图与操作按钮使用圆角样式。“适应宽度”和缩放比例通过圆角浮层选择。
- PPTX 渲染引擎随 Web 发布，适用于 macOS 和 Linux 设备。预览在独立的浏览器框架内运行，阻止外部资源请求，关闭后释放渲染资源。
- 沿用会话文件的读取权限，校验 PPTX 包和 XML。文件上限为 8 MiB，解压后总量上限为 64 MiB。复杂内容可下载原文件查看。

通信协议为 **v96**，Claude Agent SDK 版本为 **0.2.174**。Relay、Web 与 Wrapper 需配套升级，应用内维护更新通道可跨协议版本完成升级。

```sh
cc-remote update --check --version 5.3.45
cc-remote update --version 5.3.45
```

安装与升级步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.45/docs/installation.md)。

## English

This release adds embedded PPTX previews for slides generated in your sessions, on phones and desktop browsers.

- Navigate slides, open thumbnails, adjust zoom and download the original file. Mobile previews use continuous vertical reading with controls at the bottom.
- Rounded slide cards, thumbnails and controls share a custom rounded menu for fit-to-width and zoom selection.
- The PPTX renderer ships with the Web client and supports files from macOS and Linux devices. Rendering runs in an isolated browser frame, blocks external resources and releases resources when the preview closes.
- Existing session file authorization applies. Package and XML validation limit the original file to 8 MiB and total expanded content to 64 MiB. Download the original file to view complex content in a presentation application.

Wire protocol is **v96**. Claude Agent SDK version is **0.2.174**. Upgrade Relay, Web and Wrapper together using the cross-version maintenance update channel.

Follow the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.45/docs/installation_en.md) for setup and upgrades.
