# cc-remote v5.3.12

## 中文

完成 **DSH 0.2.2-rc.1** 的控制、定时任务与插件管理适配，统一工作状态提示，并完善 Relay 发布目录清理。

- 定时任务支持原生目标选择、编辑和立即运行。批量清理只删除确认过的任务，逐项校验版本；遇到冲突或结果不确定即停止，避免误删刚结束的任务、私有任务或重复执行。
- 增加性能统计、已配置插件源的市场浏览与安装、兼容版本更新，以及可选推荐卡片。
- 补回定时任务的原始输入，修复归档后多余的历史分页提示，保留后台任务和子代理返回的继续处理边界；DeepSeek 继续处理样式与 Claude 对齐。
- 会话删除采用 cc-remote 的居中确认框。
- Claude、Codex 和 DSH 共用橙色流光词及省略号，移除工作状态行的上传、下发 token 计数。
- Claude 工作中的动画采用花形与六阶段呼吸交替循环；保留静态花形的点击回放、Codex 和 DSH 原有火花，以及明确的原生进度提示。
- Relay 使用独立启动入口，支持复用经审阅且绑定文件指纹的清理清单。清理前仍重新检查直接路径、软链接和运行中依赖，保留当前版本及完整回滚版本；无法确认的旧文件继续保留。

通信协议保持 **v90**，Claude Agent SDK 保持 **0.2.174**。DSH 原生运行时单独维护；本次 cc-remote 更新不会替换或重启原生 DSH、Codex 或独立 Claude 会话服务。Worktree 和 DSH 侧聊 UI 不在本次范围内。

```sh
cc-remote update --check --version 5.3.12
cc-remote update --version 5.3.12
```

更新器先验证并升级已配对的 Relay，再更新当前设备；其他设备需各自更新。更新前等待进程内侧聊和排队消息完成，更新后重新加载 Web/PWA。

发布继续包含鸿蒙 **0.1.0-preview.6** 未签名 HAP、构建元数据和独立校验文件，沿用已验证的原生构建；已安装 preview.6 无需重装。HAP 需要使用自己的开发者及设备 Profile 签名。本次没有新的 Desktop 安装包。

## English

Complete **DSH 0.2.2-rc.1** control, scheduling and plugin integration, refresh working indicators, and improve Relay release retention.

- Support native schedule destinations, editing and run-now. Cleanup deletes only confirmed identities with per-task revision checks, stopping on conflicts or uncertain results without including newly ended or private tasks or replaying mutations.
- Add performance statistics, browsing and installation from configured plugin sources, compatible package updates and optional recommendations.
- Restore scheduled inputs, correct archive pagination, preserve background-job and subagent continuation boundaries, and align DeepSeek continuation receipts with Claude's presentation.
- Use cc-remote's centered confirmation for session deletion.
- Share orange shimmer words with an ellipsis across Claude, Codex and DSH, and remove input/output token counters from the working status row.
- Alternate Claude's live flower animation with a six-stage breathing sequence. Preserve static click replay, Codex/DSH sparks and explicit native progress messages.
- Give Relay an isolated entrypoint and reusable fingerprint-bound retention reviews. Rediscover literal paths, symlinks and live dependencies before cleanup, retain the active and complete rollback generation, and defer uncertain artifacts.

Wire protocol **v90** and Claude Agent SDK **0.2.174** are unchanged. Native DSH is maintained separately; updating cc-remote does not replace or restart native DSH, Codex or the independent Claude session service. Worktree and DSH side-chat UI remain out of scope.

```sh
cc-remote update --check --version 5.3.12
cc-remote update --version 5.3.12
```

The updater verifies and upgrades the paired Relay before the current device. Update other devices individually, let in-process side chats and queued messages finish first, and reload Web/PWA afterwards.

Assets retain the verified HarmonyOS **0.1.0-preview.6** unsigned HAP, native-build metadata and separate checksums. Existing preview.6 users need no native reinstall; the HAP requires your own developer/device signing profile. No new Desktop installer is included.
