# cc-remote v5.3.47

## 中文

本次更新增加后台文件查看，修复账户额度显示和 Claude 计划审批。

- Claude Code 和 Codex 可以在工作区内后台查看图片、SVG、PDF、PPTX、DOCX、静态 HTML、Markdown 和 Mermaid。支持的格式可选择页码或画面。
- XLSX、CSV 和 TSV 支持按范围查看截图，或读取文件中保存的单元格值和公式。
- Codex 状态页和额度界面统一使用当前账号的主额度套餐，并说明项目通知配置、MCP 配置和恢复会话时的模型变更。
- Claude 额度弹层显示已验证的套餐名称，并在上游提供数据时显示 Fable 专项周额度。Claude 和 Codex 的模型列表保留说明和选中标记，去掉左侧装饰图标。
- Claude Agent SDK 升至 0.2.184。独立账号可以正常启动，批准计划时选择的权限模式会应用到当前会话。

通信协议为 **v97**。Relay、Web 和 Wrapper 请配套升级。运行中的独立 Claude 会话服务按安全更新流程交接。

```sh
cc-remote update --check --version 5.3.47
cc-remote update --version 5.3.47
```

安装与升级步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.47/docs/installation.md)。

## English

This release adds background file inspection and fixes account quota display and Claude plan approval.

- Claude Code and Codex can inspect workspace images, SVG, PDF, PPTX, DOCX, static HTML, Markdown and Mermaid in the background. Select a page or frame where supported.
- For XLSX, CSV and TSV, view a range as a screenshot or read the saved cell values and formulas.
- Codex status and quota views use the current account quota to show the subscription tier. The status sheet explains known project notification, MCP configuration and resume model diagnostics.
- Claude quota shows verified plan names and reported Fable weekly usage. The Claude and Codex model pickers keep descriptions and selection marks in a simpler list.
- Claude Agent SDK 0.2.184 supports the updated isolated-account startup flow and applies the approved plan permission mode to the current session.

Wire protocol is **v97**. Upgrade Relay, Web and Wrapper together through the maintenance update channel. Follow the safe handoff procedure for any active independent Claude service.

See the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.47/docs/installation_en.md) for setup and upgrades.
