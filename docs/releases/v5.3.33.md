# cc-remote v5.3.33

## 中文

本次更新修复 Claude 过程详情加载失败和 Codex 回复显示不完整的问题。

- Claude 过程详情分页保留原始轮次身份，压缩后缺少用户消息标记的历史记录也能正确加载。
- Codex 在收到完整回复时校正实时显示的文本，并在读取已结束轮次时恢复完整正文。
- 保留已有过程详情，拒绝过期轮次更新，避免补全文本时覆盖其他轮次。
- 重连回放保留文本替换边界，避免部分回复与完整回复重复拼接。

发布通信协议为 **v94**，Claude Agent SDK 版本为 **0.2.174**。Relay 与 Web 配套升级，Wrapper 通过独立维护通道逐台升级。

```sh
cc-remote update --check --version 5.3.33
cc-remote update --version 5.3.33
```

查看安装与升级步骤。[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.33/docs/installation.md)

## English

This update fixes Claude process-detail loading and incomplete Codex replies.

- Preserve the original Claude turn identity on every detail page, including compacted history without an explicit user marker.
- Reconcile streamed Codex text with complete replies and restore the full body when loading settled turns.
- Preserve process details and reject stale turn updates when reconciling reply text.
- Keep text replacement boundaries during reconnect replay to prevent partial and complete replies from being concatenated.

Wire protocol is **v94**. Claude Agent SDK version is **0.2.174**. Upgrade Relay and Web together, then upgrade Wrappers individually through maintenance.

The commands above select this release explicitly. Follow the installation guide for setup and upgrades. [Installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.33/docs/installation_en.md)
