# cc-remote v5.3.25

## 中文

本次更新修复会话历史恢复、处理中输出与原生提问弹层的交互问题。

- Wrapper 重启或升级后，正确识别 Claude 后台任务通知并恢复原生会话历史，修复刷新后仍残留的“回复未完成”、异常耗时与污染的浏览器缓存。
- 将普通异步通知归入处理过程，并根据实际最终回答确认完成状态。
- 在 Claude、Codex、DSH 之间切换时，保留提问弹层中的输入、选项、步骤与阅读位置。成功回答后清理对应草稿。
- DSH 的单题和批量提问显示正确的引擎名称。鼠标打开引擎菜单后，可按 Escape 关闭并恢复触发按钮的焦点，中文输入法确认操作也有相应处理。

发布协议为 **v90**，Claude Agent SDK 版本为 **0.2.174**。

```sh
cc-remote update --check --version 5.3.25
cc-remote update --version 5.3.25
```

独立服务器更新的首次启用与恢复操作见[应用内更新说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.25/docs/in-app-updates.md)。

## English

This update repairs session history recovery, asynchronous progress rendering and native question dialogs.

- Recognize Claude background task notifications and restore canonical history after Wrapper restarts or upgrades. Rebuild browser caches containing stale incomplete replies, inflated durations or internal notifications.
- Keep plain asynchronous notices within the working process and use the actual final answer to establish completion.
- Preserve question input, selections, page and reading position when switching between Claude, Codex and DSH. Retire the corresponding drafts after successful answers.
- Show DSH in its single and batch question headings. Escape closes pointer-opened harness menus and restores trigger focus, with IME confirmation handling preserved.

Wire protocol is **v90**. Claude Agent SDK version is **0.2.174**.

Use the update commands above. See the [in-app update guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.25/docs/in-app-updates.md) for independent server update setup and recovery.
