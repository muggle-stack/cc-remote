# cc-remote v5.3.44

## 中文

本次更新修复 Codex 上下文设置长期待确认的问题，并对齐 Claude 与 Codex 的上下文操作。

- 共享 Codex 会话使用新的原生运行记录确认设置生效，支持恢复默认上下文，校验记录时间、会话、模型、容量及压缩阈值。
- 点击上下文圆环查看用量详情，空参数 `/autocompact` 打开设置面板，轮询更新保留尚未提交的输入。
- Claude 主会话和侧聊显示模型最大窗口、当前窗口及实际压缩阈值。上限来自原生 CLI 的本地控制查询。
- 超限预设会禁用，自定义输入会提示超限，后台在保存、启动与应用设置前复核上限。读取失败时提示重试并保留已有设置。

共享 Codex 线程仍由官方 app-server 决定何时加载配置。其他 App 或 CLI 保持线程订阅时，设置可能继续等待原生确认，释放对应连接后可重新选择。

Claude 上限查询沿用原生 CLI 当前支持的 100K–1M 配置范围。

通信协议为 **v95**，Claude Agent SDK 版本为 **0.2.174**。Relay、Web 与 Wrapper 需配套升级，应用内维护更新通道可跨协议版本完成升级。

```sh
cc-remote update --check --version 5.3.44
cc-remote update --version 5.3.44
```

安装与升级步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.44/docs/installation.md)。

## English

This release fixes pending Codex context settings and aligns context controls across Codex and Claude.

- Confirm shared Codex context preferences, including restored defaults, from fresh native records validated against the session, model, capacity and compaction threshold.
- Open read-only usage details from the context ring and settings with bare `/autocompact`. Preserve unsent input during polling updates.
- Show Claude model window limits, the current configured window and the effective compaction threshold in main sessions and side chats. Read limits through local native CLI control queries.
- Disable oversized presets, validate custom input and recheck limits before saving, launching or applying settings. Failed reads preserve existing settings and allow retry.

The official app-server controls when a shared Codex thread reloads configuration. A thread still subscribed by another App or CLI may keep settings pending until that connection releases the thread and the user selects the setting again.

Claude limit discovery follows the native CLI's currently supported 100K–1M configuration range.

Wire protocol is **v95**. Claude Agent SDK version is **0.2.174**. Upgrade Relay, Web and Wrapper together using the cross-version maintenance update channel.

Follow the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.44/docs/installation_en.md) for setup and upgrades.
