# cc-remote v5.3.26

## 中文

本次更新修复部署文件累积、多设备历史缓存和后台通知问题。

- 部署准备失败或中断时回收未完成的 Wrapper 环境，整理已核实可回收的旧部署代际与回滚残留。
- 清理前核对运行进程、服务、原生账号配置和符号链接依赖，支持按安装所有者执行管理员检查，并在更新界面显示待完成的清理。
- 切换设备时保留会话历史、分页缓存和重连游标，按设备隔离同名 session。旧版未隔离缓存会在首次加载时重建。
- Web Push 和鸿蒙推送覆盖全部已授权设备，接收后台任务完成与等待回答通知。订阅更新采用原子替换，退出登录或移除设备时清理相应订阅。

发布协议为 **v90**，Claude Agent SDK 版本为 **0.2.174**。

```sh
cc-remote update --check --version 5.3.26
cc-remote update --version 5.3.26
```

安装和升级步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.26/docs/installation.md)。

## English

This update repairs deployment storage accumulation, multi-device history caching and background notifications.

- Reclaim incomplete Wrapper environments after failed or interrupted staging and retire verified obsolete deployment generations and rollback artifacts.
- Check live processes, services, native account configuration and symlink dependencies during cleanup. Support owner-aware administrator checks and show deferred retention in the update UI.
- Preserve session history, pagination caches and reconnect cursors across device switches, with device isolation for matching native session IDs. Legacy unscoped browser caches rebuild once.
- Keep Web Push and Harmony subscriptions bound to every authorized device for task completion and question notifications. Replace groups atomically and remove the appropriate bindings on logout or device revocation.

Wire protocol is **v90**. Claude Agent SDK version is **0.2.174**.

Use the update commands above. See the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.26/docs/installation_en.md) for setup and upgrades.
