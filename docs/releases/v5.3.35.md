# cc-remote v5.3.35

## 中文

本次更新改善切换 harness 时的侧边面板体验，修复 DSH 终端滚动并降低测试运行开销。

- 侧边聊天、文件预览和视频在切换 harness 时保留已挂载界面，返回后继续使用原有草稿、阅读位置和播放进度。
- 手动关闭面板会释放对应实例、订阅及媒体资源。切换设备或内容失效也会清理，后台面板保留数量有上限。
- 隐藏面板暂停媒体播放、自动读取和弹窗交互，多个面板按各自的会话和请求接收回复。
- DSH 终端累积 Mac 触控板的小幅滚动增量，保留全屏终端程序的鼠标输入。待发送按键与连续输出合并处理，输出完成解析后再确认游标。
- Python 测试合并独立执行项并保留全部参数覆盖，移除模拟重试中的真实等待，缩短测试 HTTPS 服务的退出等待。

发布通信协议为 **v94**，Claude Agent SDK 版本为 **0.2.174**。

```sh
cc-remote update --check --version 5.3.35
cc-remote update --version 5.3.35
```

查看安装与升级步骤。[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.35/docs/installation.md)

## English

This update improves side-panel continuity across harness switches, fixes DSH terminal scrolling and reduces test overhead.

- Keep side chats, file previews and videos mounted across harness switches, preserving drafts, reading positions and playback progress.
- Release panel instances, subscriptions and media resources on explicit close, device changes and content invalidation. Retained panels have a bounded capacity.
- Pause hidden media, automatic reads and popup interaction, and route panel replies by their session and request identity.
- Accumulate fine Mac trackpad scroll deltas in the DSH terminal while preserving mouse input for full-screen programs. Batch queued keystrokes and continuous output, acknowledging output after parsing completes.
- Consolidate Python test execution items while retaining all parameter coverage, remove real waits from simulated retries and shorten test HTTPS server shutdown.

Wire protocol is **v94**. Claude Agent SDK version is **0.2.174**.

The commands above select this release explicitly. Follow the installation guide for setup and upgrades. [Installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.35/docs/installation_en.md)
