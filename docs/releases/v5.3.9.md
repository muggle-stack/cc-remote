# cc-remote v5.3.9

## 中文

改进连续引导、提问提醒、音视频画廊和 BTW 侧聊，并修复 Linux 会话只读误判及 `/goal` 历史刷新后的停更。

- Claude 可在前一条引导尚未回显时继续接收引导；每条输入独立确认，断线重连后仍按准确的原生消息标识对应。
- Claude 实时提问时使用已配置的系统通知渠道提醒；重放提问不重复通知，也不额外弹出应用内提示。通用提醒不包含会话名称或问题内容。
- 远程页面最多可登记 256 个音视频元素，按可见范围或播放请求加载，同时最多保留八个播放器，回收已暂停媒体的缓冲并保留播放位置。
- 已读 BTW 完成提醒不再因切换会话而重复出现。侧边和居中聊天均可查看各自后台任务；子代理条目展示已有进度，不打开独立工作页。
- 兼容 Linux 上 Claude 登记的进程启动时钟值，避免其他会话被错误锁为只读。
- `/goal` 执行时刷新历史或切换会话后仍能继续显示输出；临时 API 错误后继续执行的内容不会被错误标成最终失败。派生历史索引升级至 v57，原始对话记录不变。

通信协议从 **v86 升级至 v87**，Claude Agent SDK 保持 **0.2.174**。请在同一维护窗口升级 Relay 和所有 Wrapper，再刷新 Web/PWA。已部署 v87 开发版的安装也应更新到本次正式发布。

```sh
cc-remote update --check --version 5.3.9
cc-remote update --version 5.3.9 --allow-protocol-change
```

更新器先验证并升级已配对的 Relay，再更新当前设备；其他设备需各自执行更新。普通 Wrapper 更新保留独立 Claude 会话服务，仍在 Wrapper 内运行的侧聊和排队消息需先完成。

发布包含六个平台的 Relay/Wrapper 包、`install.sh`、`SHA256SUMS`，以及已校验的鸿蒙未签名 HAP、`MOBILE_BUILD_INFO.json` 和 `MOBILE_SHA256SUMS`。鸿蒙包保留真实原生版本 **0.1.0-preview.5**，需要自行签名；已有相同原生版本的用户无需重装。本次没有新的 Desktop 安装包。

## English

Improve consecutive steering, question alerts, media galleries and BTW side chats, and repair Linux ownership detection and `/goal` output after history refreshes.

- Accept another Claude steering input before earlier inputs echo back. Track each receipt independently and reconcile exact native message identities after reconnects.
- Notify live Claude questions through the configured system notification channel. Replayed questions stay silent, with no additional in-app popup. Generic alerts exclude session names and question content.
- Register up to 256 media elements and load visible or explicitly played media, with at most eight resident players. Retire paused buffers while retaining playback position.
- Keep read BTW completion reminders dismissed across session switches. Show each side chat's own background tasks in docked and centered layouts; agent rows show existing progress without opening a separate workspace.
- Accept Claude's Linux process start ticks so unrelated sessions are not incorrectly made read-only.
- Preserve `/goal` output ownership after history refreshes or session switches. Provider errors followed by continued work remain progress rather than a final failure. Derived history indexes advance to v57 without changing native transcripts.

Wire protocol changes from **v86 to v87**; Claude Agent SDK remains **0.2.174**. Upgrade the Relay and every Wrapper in the same maintenance window, then reload Web/PWA. Installations running a v87 development snapshot should also upgrade to this published release.

```sh
cc-remote update --check --version 5.3.9
cc-remote update --version 5.3.9 --allow-protocol-change
```

The updater verifies and upgrades the paired Relay before activating the local device. Update other devices individually. Ordinary Wrapper updates preserve the independent Claude session service; in-process side chats and queued messages must finish first.

The release includes six platform-specific Relay/Wrapper bundles, `install.sh`, `SHA256SUMS`, and a verified unsigned HarmonyOS HAP with `MOBILE_BUILD_INFO.json` and `MOBILE_SHA256SUMS`. The native HarmonyOS version remains **0.1.0-preview.5** and requires signing. Existing users of that native version do not need to reinstall it. No new Desktop installer is included.
