# cc-remote v5.3.52

## 中文

- 会话运行、中断或收尾期间，侧栏和确认弹窗中的删除按钮会变灰。
- 父会话仍有派生会话，或 Codex daemon 无法连接时，状态栏会显示具体原因。删除失败时会保留未发送的草稿。
- 在 Codex App 归档、取消归档或永久删除会话后，cc-remote 会自动刷新侧栏。

本版使用通信协议 v97。更新步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.52/docs/installation.md)。

## English

- Session deletion is disabled while a turn is running, interrupting, or draining. This also applies when the confirmation dialog is already open.
- The status bar explains when a descendant session must be deleted first or when the Codex daemon is unavailable. Failed deletions preserve unsent drafts.
- The sidebar refreshes automatically when a session is archived, restored, or permanently deleted in Codex App.

This release uses wire protocol v97. See the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.52/docs/installation_en.md) for update instructions.
