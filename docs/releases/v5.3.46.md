# cc-remote v5.3.46

## 中文

本次更新修复 Codex 多提供方下的模型控制，并补齐新版 Work 子代理限制。

- 模型列表、思考强度和速度档位按账号与会话所属提供方读取。切换默认提供方后，旧会话仍使用自己的模型目录。
- 恢复与派生会话时沿用原提供方，避免错误替换模型或套用其他提供方的思考强度、速度权限。
- Work 同时关闭 Codex 新旧两代子代理入口，保持 Work 的独立执行边界。
- Web 和 TUI 按会话接收模型目录，防止迟到或其他账号的响应覆盖当前选择。读取失败时保留对应会话已有的目录。

通信协议为 **v97**，Claude Agent SDK 版本为 **0.2.174**。Relay、Web 与 Wrapper 需配套升级，应用内维护更新通道可跨协议版本完成升级。

```sh
cc-remote update --check --version 5.3.46
cc-remote update --version 5.3.46
```

安装与升级步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.46/docs/installation.md)。

## English

This release fixes Codex model controls across providers and completes Work's subagent restrictions for newer Codex versions.

- Read models, reasoning levels and speed tiers from the account and provider that owns each thread. Changing the default provider no longer changes an existing thread's catalog.
- Preserve the original provider when restoring or forking a thread, avoiding incorrect model replacements or another provider's reasoning and speed capabilities.
- Disable both native Codex subagent generations in Work mode.
- Route Web and TUI model catalogs by account and session. Late or unrelated replies cannot replace the current selection; failed reads retain that session's previous catalog.

Wire protocol is **v97**. Claude Agent SDK version is **0.2.174**. Upgrade Relay, Web and Wrapper together using the cross-version maintenance update channel.

Follow the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.46/docs/installation_en.md) for setup and upgrades.
