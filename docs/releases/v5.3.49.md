# cc-remote v5.3.49

## 中文

关闭主动额度查询时，Claude 账户额度面板右上角也能显示当前账号本机缓存的套餐名，例如 Ultra。缓存缺少明确的套餐名时，徽标保持隐藏。

通信协议为 v97。安装与升级见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.49/docs/installation.md)。

## English

The Claude account quota panel can display a plan such as Ultra using the current account's local cache while active quota queries are off. If the cache lacks a recognized plan name, the badge stays hidden.

This release uses wire protocol v97. See the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.49/docs/installation_en.md) for setup and upgrades.
