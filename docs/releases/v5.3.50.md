# cc-remote v5.3.50

## 中文

Web/PWA 支持长按波形按钮实时转写。松手后保留可编辑草稿，确认后发送。已完成的回复可点喇叭流式朗读，停止或播放完成后释放音频缓冲。

语音入口默认隐藏。在 Relay 配置 `DOUBAO_VOICE_API_KEY` 后，Web/PWA 显示可用的语音控件。麦克风权限由浏览器在录音时询问。

通信协议为 v97。配置见[语音输入与朗读](https://github.com/muggle-stack/cc-remote/blob/v5.3.50/docs/configuration.md#语音输入与朗读)，安装与升级见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.50/docs/installation.md)。

## English

Press and hold the waveform button in Web/PWA for live dictation. Release to keep an editable draft, then send it when ready. Play any completed reply as streaming audio. The playback buffer is released when playback stops or finishes.

Voice controls appear after a Doubao Voice project key is configured in the Relay with `DOUBAO_VOICE_API_KEY`. The browser prompts for microphone permission when recording starts.

This release uses wire protocol v97. See the [configuration guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.50/docs/configuration.md) and [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.50/docs/installation_en.md).
