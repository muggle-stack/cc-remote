# cc-remote v5.3.8

## 中文

支持远程 MP4/M4V 播放，减少页面预览等待和重复加载，并修复部署后的页面更新恢复。

- 视频文件使用带鉴权的 HTTP Range 播放；远程页面可先显示内容，再按需加载音视频。
- 切换会话或 Claude/Codex 时保留最近三个页面预览，简化预览标题栏和页面选择。
- 修复鸿蒙 App 中预览资源缓存失效，以及中文句号被错误纳入网址的问题。
- 文件回滚受限改为紧凑状态提示，可展开查看原因。
- 新 Web 版本提供安全更新入口；协议不兼容时不会被只读握手请求卡住，服务端回滚后继续恢复连接。未保存编辑和待确认操作仍阻止更新。Relay 重启后仍需重新登录。

通信协议从 **v85 升级至 v86**，Claude Agent SDK 保持 **0.2.174**。请在同一维护窗口升级 Relay 和所有 Wrapper，再刷新 Web/PWA。已部署 v86 开发版的安装也应更新到本次正式发布。

```sh
cc-remote update --check --version 5.3.8
cc-remote update --version 5.3.8 --allow-protocol-change
```

更新器先验证并升级已配对的 Relay，再更新当前设备；其他设备需各自执行更新。普通 Wrapper 更新保留独立 Claude 会话服务，仍在 Wrapper 内运行的侧聊和排队消息需先完成。

发布包含六个平台的 Relay/Wrapper 包、`install.sh`、`SHA256SUMS`，以及已校验的鸿蒙未签名 HAP、`MOBILE_BUILD_INFO.json` 和 `MOBILE_SHA256SUMS`。鸿蒙包保留真实原生版本 **0.1.0-preview.5**，需要自行签名；已有相同原生版本的用户无需重装。本次没有新的 Desktop 安装包。

## English

Add remote MP4/M4V playback, reduce preview startup and reloads, and repair Web update recovery after deployment.

- Play video files through authenticated HTTP Range requests. Remote pages render before loading audio/video on demand.
- Retain the three most recent page previews across session and Claude/Codex switches, with a simpler header and page picker.
- Fix stale preview-runner caching in the HarmonyOS App and exclude Chinese sentence punctuation from bare URL links.
- Show limited file rollback as compact status feedback with an expandable explanation.
- Offer guarded Web updates without blocking on read-only requests rejected by an incompatible protocol handshake. Continue reconnect recovery after a server rollback. Unsaved edits and unconfirmed mutations still prevent updates. Relay restarts continue to require signing in again.

Wire protocol changes from **v85 to v86**; Claude Agent SDK remains **0.2.174**. Upgrade the Relay and every Wrapper in the same maintenance window, then reload Web/PWA. Installations running a v86 development snapshot should also upgrade to this published release.

```sh
cc-remote update --check --version 5.3.8
cc-remote update --version 5.3.8 --allow-protocol-change
```

The updater verifies and upgrades the paired Relay before activating the local device. Update other devices individually. Ordinary Wrapper updates preserve the independent Claude session service; in-process side chats and queued messages must finish first.

The release includes six platform-specific Relay/Wrapper bundles, `install.sh`, `SHA256SUMS`, and a verified unsigned HarmonyOS HAP with `MOBILE_BUILD_INFO.json` and `MOBILE_SHA256SUMS`. The native HarmonyOS version remains **0.1.0-preview.5** and requires signing. Existing users of that native version do not need to reinstall it. No new Desktop installer is included.
