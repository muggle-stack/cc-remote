# cc-remote v4.0.8

## 中文

v4.0.8 新增 Codex 原生跨会话消息查看，改善手机侧栏交互，修复会话状态、模型恢复
和部署清理。产品版本 **4.0.8**，通信协议升级为 **v74**，Claude Agent SDK
保持 **0.2.157**。

### 本次更新

- **跨会话消息**：显示 Codex 原生消息的来源与实际发送结果；点击会话链接打开
  同设备、同账号下的只读历史，关闭后保留原对话阅读位置。发送仍由可选的官方
  Codex App 工具完成；本功能不会自动安装或启用发送工具。
- **手机侧栏**：正文浮在侧栏上方，增加圆角、柔和遮罩与模糊效果，适配明暗主题；
  改善快速反复打开、收回及动画中反向滑动的响应。支持时提供触感反馈，实际反馈
  取决于浏览器、操作系统及设备设置。
- **电脑侧聊**：稳定打开右侧 BTW 时的正文宽度，减少布局抖动。
- **Claude 显示**：实时历史刷新时保留“继续处理”的消息顺序；避免较慢的会话列表
  返回后，把已完成的会话重新显示为运行中。
- **Codex 模型**：恢复较长会话时保留原生模型与设置，避免用户选择被历史模型覆盖。
- **部署清理**：保留当前版本、一套完整的上一版回滚备份，以及仍被运行进程或
  未完成事务使用的文件。保留目录的间接依赖同样受到保护；无法完整读取进程引用时
  停止清理。Codex daemon 生命周期命令使用稳定的用户目录，验收增加只读配置查询。

### 升级

**协议从 v73 升至 v74，旧 Wrapper/Web 不能与新 Relay 混用。** 安排同一维护窗口，
先停止不兼容的旧 Wrapper，更新 Relay + Web，再更新并启动全部 Wrapper。
安装器管理的部署在独立终端使用：

```bash
cc-remote update --version 4.0.8 --allow-protocol-change
```

设备更新先核对配对 VPS；已经更新到目标版本时只更新本机。其他设备仍需逐一更新，
完成后重新加载 Web/PWA。源码和容器部署保留原有流程，见
[安装与升级](https://github.com/muggle-stack/cc-remote/blob/v4.0.8/docs/installation.md)。

从 v4.0.7 升级不需要为本次修复重启独立 Claude 会话服务。更早版本仍需遵循
[Claude 服务迁移指南](https://github.com/muggle-stack/cc-remote/blob/v4.0.8/docs/claude-session-service.md)，
等待原生任务和待处理输入结束。普通 Wrapper 更新保留独立服务及其任务。
Codex 派生历史与浏览器缓存会按需重建，原生会话记录保持不变。

本次发布 Web、Relay 和 Claude/Codex Wrapper，提供 Linux Relay、Linux/macOS
Wrapper 的 x86_64 与 arm64 包；不包含实验分支的 DSH 或 Desktop 安装包。

## English

v4.0.8 adds native Codex cross-session message views, improves mobile drawers,
and fixes session state, model restoration and deployment cleanup. Product
version **4.0.8**, wire protocol **v74**, Claude Agent SDK **0.2.157**.

- **Cross-session messages:** show native sources and actual delivery outcomes.
  Conversation links open read-only history within the same device and account;
  closing the view preserves the original reading position. Sending still uses
  the optional official Codex App tools, which this feature does not install or
  enable automatically.
- **Mobile drawers:** place the rounded conversation above the sidebar, with
  softer shading and blur in both themes. Improve repeated swipes and reversals
  during transitions. Feedback is optional and depends on browser support,
  operating-system behavior and device settings.
- **Desktop side chats:** stabilize the conversation width when opening BTW.
- **Claude display:** preserve continuation ordering through live history
  refreshes, and prevent a delayed session list from restoring a completed
  session's running badge.
- **Codex models:** preserve native model selection and settings when resuming
  long conversations instead of restoring an older model.
- **Deployment cleanup:** retain the current release, one complete rollback
  generation, and files used by live processes or unresolved transactions.
  Follow retained artifacts' indirect dependencies and refuse cleanup when
  process references cannot be fully inspected. Run Codex daemon lifecycle
  commands from a stable home directory and verify live configuration reads
  during deployment acceptance.

### Upgrade

**Protocol v74 is incompatible with v73.** Coordinate every tier in one
maintenance window: stop incompatible old Wrappers, upgrade Relay + Web, then
upgrade and start all Wrappers. For installer-managed deployments, run
`cc-remote update --version 4.0.8 --allow-protocol-change` in an independent
terminal. Device updates verify the paired Relay first and skip its upgrade
when already current. Update other devices individually and reload Web/PWA.
Source and container deployments retain their existing procedures; see the
[installation guide](https://github.com/muggle-stack/cc-remote/blob/v4.0.8/docs/installation_en.md).

Upgrading from v4.0.7 does not require restarting the independent Claude
session service for these fixes. Older deployments must still follow the
[service migration guide](https://github.com/muggle-stack/cc-remote/blob/v4.0.8/docs/claude-session-service.md)
after native work and pending input drain. Ordinary Wrapper upgrades preserve
the independent service and its tasks. Derived Codex history and browser caches
rebuild as needed; native session records remain unchanged.

Release assets contain Web, Relay and Claude/Codex Wrappers: Linux Relay and
Linux/macOS Wrapper packages for x86_64 and arm64. Experimental DSH and Desktop
installers are not included.
