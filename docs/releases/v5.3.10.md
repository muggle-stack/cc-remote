# cc-remote v5.3.10

## 中文

修复 Claude 后台任务多次返回时的历史合并、处理耗时和阅读位置，并补齐目录操作、Work 权限、页面缩放及鸿蒙下载。

- Claude 历史按每次回复保留过程项数和原生时间。重新登录、展开详情、收起过程或刷新后台续写时，保留原始回复和各段“继续处理”，避免缺失、错位及耗时变化。
- 正文输出完成、消息 ID 确认及过程自动折叠时，保留正在阅读的段落；位于底部时继续跟随输出。展开的续写详情不会因冷历史加载而再次收起，触屏松手恰逢完成时也保持阅读位置。
- 前台回复结束后发送新消息，保留仍在运行的 Claude 后台任务。后台工作暂时阻止重连时，保留排队消息和附件，条件允许后继续发送。
- Work 支持与 Code 相同的权限配置，按会话保存并由侧聊继承。
- Code 目录菜单集中提供新建、归档和删除会话。批量操作按设备与账号确认范围，跳过运行中、有后台任务或排队消息的会话，保留项目文件；空闲的未归档 Codex 会话也可直接删除。点击或轻触菜单外部即可收起。
- Codex 归档与取消归档使用原生索引快速刷新；压缩历史中的已结束子代理不再变成虚假的后台任务。上下文设置与原生运行状态一致时，不再显示“等待生效”。
- HTML 页面预览支持缩放、适应宽度和还原，以及触控板和触屏手势；保留页面状态与隔离边界。手机文件预览操作按钮保持靠右对齐。
- 鸿蒙原生 App 升级至 **0.1.0-preview.6**，支持保存生成的图片、文档和需要登录态的媒体，通过系统文件保存窗口选择位置，并处理取消、失败与重试。图片保存到文件，不会自动加入相册。

通信协议从 **v87 升级至 v90**，Claude Agent SDK 保持 **0.2.174**。请在同一维护窗口升级 Relay 和所有 Wrapper，再刷新 Web/PWA。Claude 派生历史索引升级至 v59，原始会话记录不变。

```sh
cc-remote update --check --version 5.3.10
cc-remote update --version 5.3.10 --allow-protocol-change
```

更新器先验证并升级已配对的 Relay，再更新当前设备；其他设备需各自更新。普通 Wrapper 更新保留独立 Claude 会话服务，仍在 Wrapper 内运行的侧聊和排队消息需先完成。

发布包含六个平台的 Relay/Wrapper 包、安装脚本及校验文件，以及鸿蒙未签名 HAP 和独立构建元数据。鸿蒙 preview.6 已完成真机图片、文档、登录态媒体下载和取消重试验证；使用旧原生版本的用户需自行签名并覆盖安装新版 HAP，才能获得下载功能。已安装 preview.6 的用户无需重装。本次没有新的 Desktop 安装包。

## English

Repair Claude history grouping, process durations and reading position across repeated background-task returns, and add directory actions, Work permission controls, page zoom and HarmonyOS downloads.

- Preserve process counts and native timestamps for each Claude response. Fresh login, detail expansion, collapse and background-summary refresh retain the original answer and each continuation without missing rows, reordered content or changing durations.
- Keep the current reading paragraph when streaming ends, message IDs are confirmed or process sections collapse. Continue following output only when already at the bottom. Keep expanded continuation details open after cold-history loading, including completion coinciding with touch release.
- Preserve running Claude background tasks when another message follows a foreground result. Keep queued prompts and attachments while background work prevents a required reconnect, then resume when safe.
- Add Code-equivalent permissions to Work, persisted per session and inherited by side chats.
- Put New Session, Archive and Delete in the Code directory menu. Confirm device/account scope, skip sessions with active work, background tasks or queued messages, and retain project files. Idle unarchived Codex sessions can also be deleted directly. Outside clicks and taps dismiss the menu.
- Refresh Codex archive changes through the native index. Completed agents in compressed history no longer reappear as background work. Context settings stop showing a pending state once native runtime capacity matches the saved value.
- Add HTML preview zoom, fit-to-width, reset and trackpad/touch gestures while retaining page state and isolation. Keep mobile file-preview actions right-aligned.
- Upgrade the native HarmonyOS app to **0.1.0-preview.6**. Save generated images/documents and authenticated media through the system file picker, with cancellation, failure and retry handling. Images save to Files, not automatically to the photo library.

Wire protocol changes from **v87 to v90**; Claude Agent SDK remains **0.2.174**. Upgrade the Relay and every Wrapper in the same maintenance window, then reload Web/PWA. Derived Claude history indexes advance to v59 without changing native transcripts.

```sh
cc-remote update --check --version 5.3.10
cc-remote update --version 5.3.10 --allow-protocol-change
```

The updater verifies and upgrades the paired Relay before activating the local device. Update other devices individually. Ordinary Wrapper updates preserve the independent Claude session service; in-process side chats and queued messages must finish first.

Assets include six platform-specific Relay/Wrapper bundles, the installer and checksums, plus an unsigned HarmonyOS HAP and separate native-build metadata. Preview.6 passed physical-device checks for image/document downloads, authenticated media, cancellation and retry. Older native versions require signing and an in-place HAP update to gain downloads; existing preview.6 installations do not need reinstalling. No new Desktop installer is included.
