# cc-remote v5.3.61

## 中文

- 重连仍在运行的 Codex 会话时，小火花会先显示在聊天底部，等当前回合恢复后再跟随该回合。会话空闲后收起。
- 修复加粗链接紧接全角左括号时的渲染。括号说明保留在链接外，链接可正常打开。

本版使用通信协议 v98。更新步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.61/docs/installation.md)。

## English

- Show the Codex working indicator at the chat tail while reconnecting to a running session and restoring its active turn. Move the indicator to that turn once it is available and clear it at idle.
- Render bold bare URLs followed by a full-width opening parenthesis correctly. The parenthetical text stays outside the link.

This release uses wire protocol v98. See the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.61/docs/installation_en.md) for update instructions.
