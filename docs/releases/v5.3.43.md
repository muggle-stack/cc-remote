# cc-remote v5.3.43

## 中文

本次更新让 Codex 的模型选择和思考强度跟随官方 app-server 提供的数据。

- 模型列表直接展示 `model/list` 返回的名称、说明和顺序，移除固定模型列表及展示覆盖。
- 思考强度展示官方支持的档位和说明，默认值遵循本机 Codex 配置及官方模型元数据。已有有效选择继续保留，失效选择使用官方默认值处理。
- Codex 侧聊沿用官方分叉返回的设置，取消固定 `xhigh`。
- 列表读取失败时保留当前账号最近一次官方结果，首次读取失败提供重试入口。成功刷新后清除已移除的默认值。

完整本地检查和 18 项桌面、手机浏览器回归已通过，覆盖模型选择、思考强度、列表刷新和账号隔离。

通信协议为 **v94**，Claude Agent SDK 版本为 **0.2.174**。

```sh
cc-remote update --check --version 5.3.43
cc-remote update --version 5.3.43
```

安装与升级步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.43/docs/installation.md)。

## English

This release uses the official Codex app-server catalog for model selection and reasoning effort.

- Display model names, descriptions and ordering from `model/list`, removing the static Codex catalog and presentation overrides.
- Display native reasoning levels and descriptions. Defaults follow local Codex configuration and official model metadata. Preserve supported explicit choices and resolve stale choices through native defaults.
- Inherit the official fork settings for Codex side chats and remove the fixed `xhigh` override.
- Retain each account's last native catalog after a failed read and provide retry controls before initial discovery. Clear removed defaults after a successful refresh.

The complete local checks and 18 desktop/mobile browser regressions passed, covering model selection, reasoning controls, catalog refresh and account isolation.

Wire protocol is **v94**. Claude Agent SDK version is **0.2.174**.

Follow the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.43/docs/installation_en.md) for setup and upgrades.
