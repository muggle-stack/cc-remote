# cc-remote v5.3.42

## 中文

本次更新回退最近两版的 iOS 聊天键盘布局调整，处理打开输入框后页面整体下移、顶部出现大片空白的回归问题。

- 将移动视口偏移和聊天输入区底部间距恢复到 v5.3.39 的行为。
- 移除叠加文档滚动量的页面位置补偿，覆盖连续页面滚动时偏移不累计的回归场景。
- 保留 DSH 终端的单次手势切换一条历史、滚动、选字、复制粘贴及键盘开关，终端操作栏同步恢复共享底部安全区间距。

完整 Python 测试和浏览器回归已通过，iPhone 真机效果仍需更新后验证。

通信协议为 **v94**，Claude Agent SDK 版本为 **0.2.174**。

```sh
cc-remote update --check --version 5.3.42
cc-remote update --version 5.3.42
```

安装与升级步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.42/docs/installation.md)。

## English

This release reverts the iOS chat keyboard layout adjustments from the previous two versions following a regression that moved the page downward and left a large blank area above it when opening the composer.

- Restore mobile viewport positioning and composer spacing to the v5.3.39 behavior.
- Remove document-scroll compensation and cover repeated document panning without accumulating page offsets.
- Preserve DSH terminal single-step history gestures, scrolling, text selection, clipboard controls and keyboard toggling. Restore the toolbar's shared bottom safe-area spacing.

The complete Python suite and browser regressions passed. Physical-iPhone validation remains pending after updating.

Wire protocol is **v94**. Claude Agent SDK version is **0.2.174**.

Follow the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.42/docs/installation_en.md) for setup and upgrades.
