# cc-remote v5.3.22

## 中文

手机端终端状态改为在顶部终端按钮下方展开，与电脑端保持一致。

- 浮层自动避开屏幕左右边缘；横屏或可用高度不足时，内容在浮层内滚动。
- 保留刷新页面后的顶部控件位置稳定、关闭浮层后恢复按钮焦点等行为。
- 修正前端回归中过时的键盘布局检查，并将展示状态测试独立运行，避免断言失败后测试卡住。

通信协议保持 **v90**，Claude Agent SDK 保持 **0.2.174**。本次更新不更换原生引擎版本。

已启用应用内更新的设备，可从右上角「⋮ → 检查更新」进入并安装。也可使用：

```sh
cc-remote update --check --version 5.3.22
cc-remote update --version 5.3.22
```

首次启用与恢复操作见[应用内更新说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.22/docs/in-app-updates.md)。

## English

Open mobile terminal status beneath its header button, matching the desktop layout.

- Keep the popover within the horizontal viewport and scroll its contents when landscape or limited screen height leaves less room.
- Preserve stable header positions after reload and restore focus to the trigger when closing the popover.
- Correct the outdated keyboard-layout regression check and run presentation-state tests separately so failed assertions report and exit instead of hanging.

Wire protocol remains **v90** and Claude Agent SDK remains **0.2.174**. Native engine versions are unchanged.

Devices with in-app updates enabled can use **⋮ → Check for updates**, or run the commands above. See the [in-app update guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.22/docs/in-app-updates.md) for setup and recovery.
