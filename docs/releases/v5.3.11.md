# cc-remote v5.3.11

## 中文

适配官方 Codex CLI / app-server **0.167.0**，完善审批、会话置顶和已读状态同步，保留现有输入操作。

- 命令审批保留原生选项及顺序，支持准确传递保存命令规则和网络规则的决定，并展示网络目标、协议及额外权限。
- 会话的模型服务商不匹配时，显示恢复指引，避免自动新建替代会话或重复发送输入。
- Code 置顶与原生客户端同步；取消置顶会查询真实状态，避免缓存缺失或过期时只清除本地标记，同时保留无关的自定义分区。
- 实时回复和历史列表均支持原生已读确认。核对回合身份和状态版本，避免刷新后重新变成未读，也避免把新到达的结果误标为已读。
- Work 保留本地已读状态；列表刷新不会用原生状态覆盖它，包含待绑定的恢复会话，并保持账号隔离。
- 提问窗口支持安全的 Markdown 强调、代码及链接，提交的答案值保持原样。
- 识别新版 daemon 的进程记录和 Desktop 的 CLI 路径，保留日常 CLI 与 Wrapper 共用官方 daemon 的连接方式。

Tab 仍用于排队，本次不启用预测输入。通信协议保持 **v90**，Claude Agent SDK 保持 **0.2.174**。Codex CLI 仍由用户独立维护；本次 cc-remote 更新不替换或重启正在工作的原生 Codex 服务。

```sh
cc-remote update --check --version 5.3.11
cc-remote update --version 5.3.11
```

更新器先验证并升级已配对的 Relay，再更新当前设备；其他设备需各自更新。普通 Wrapper 更新保留独立 Claude 会话服务，进程内侧聊和排队消息需先完成。更新后重新加载 Web/PWA。

发布继续包含鸿蒙 **0.1.0-preview.6** 未签名 HAP、构建元数据和独立校验文件，沿用已验证的原生构建；已安装 preview.6 无需重装。HAP 需要使用自己的开发者及设备 Profile 签名。本次没有新的 Desktop 安装包。

## English

Adapt to official Codex CLI / app-server **0.167.0**, improving approvals, native pins and read-state synchronization while retaining existing input controls.

- Preserve native approval choices and order, including exact persistent command/network rule decisions and visible permission scope.
- Show recovery guidance for provider mismatches without creating replacement conversations or resubmitting input.
- Synchronize Code pins with native clients. Unpin reads authoritative state even with missing or stale catalog data, while preserving unrelated custom sections.
- Acknowledge both live results and catalog receipts through native read state. Exact turn and revision checks prevent unread badges from returning after refresh or clearing newer unseen results.
- Keep Work completion state local, including pending bindings recovered from the catalog, with account isolation.
- Render safe Markdown emphasis, code and links in question dialogs without changing submitted answer values.
- Recognize current daemon PID records and Desktop CLI paths while retaining the shared official daemon for ordinary CLI and Wrapper connections.

Tab still queues; composer predictions remain disabled. Wire protocol **v90** and Claude Agent SDK **0.2.174** are unchanged. Codex CLI remains separately maintained; updating cc-remote does not replace or restart active native Codex services.

```sh
cc-remote update --check --version 5.3.11
cc-remote update --version 5.3.11
```

The updater verifies and upgrades the paired Relay before the current device. Update other devices individually and reload Web/PWA. Ordinary Wrapper updates preserve the independent Claude service; in-process side chats and queued messages must finish first.

Assets retain the verified HarmonyOS **0.1.0-preview.6** unsigned HAP, native-build metadata and separate checksums. Existing preview.6 users need no native reinstall; the HAP requires your own developer/device signing profile. No new Desktop installer is included.
