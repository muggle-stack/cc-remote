# cc-remote v5.3.23

## 中文

服务器更新不再依赖当前选中的聊天设备。管理员可以在应用更新中单独选择服务器，并在切换设备或刷新后继续查看原任务。

- 分开显示服务器与设备的版本、更新权限和进度；设备没有服务器 SSH 权限时，不再阻止服务器独立更新。
- 服务器更新仅向全设备权限的登录账号开放，需管理员在服务器明确启用；设备权限保持原有范围。
- 复用独立系统任务、持久化回执和安装恢复流程，避免重复提交或连接中断导致重复升级。

通信协议保持 **v90**，Claude Agent SDK 保持 **0.2.174**，不更换原生引擎版本。

```sh
cc-remote update --check --version 5.3.23
cc-remote update --version 5.3.23
```

升级后，在托管服务器上启用一次独立服务器更新：

```sh
sudo cc-remote ui-updates enable --role relay
```

详见[应用内更新说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.23/docs/in-app-updates.md)。

## English

Update the server independently of the selected chat device. Administrators can select the server in the update panel and follow the same job after changing devices or reloading.

- Separate server and device versions, permissions and progress; a device no longer needs server SSH access to use independent server updates.
- Require explicit server-side opt-in and a full-scope browser login while preserving device authorization boundaries.
- Reuse durable OS jobs, receipts and installation recovery to handle retries and interrupted connections without duplicate upgrades.

Wire protocol remains **v90** and Claude Agent SDK remains **0.2.174**. Native engine versions are unchanged.

After upgrading, enable the server endpoint once with `sudo cc-remote ui-updates enable --role relay`. See the [in-app update guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.23/docs/in-app-updates.md).
