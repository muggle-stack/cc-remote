# cc-remote v5.3.24

## 中文

会话列表的选中样式与设备中心统一：左侧柔光搭配淡边框和轻背景。

- 紧凑与舒展布局采用同一套选中效果，跟随 Claude、Codex、DSH 的主题色。
- 调淡选中背景与边框，保留会话状态、账号标识和菜单交互。
- 光效不占布局空间、不拦截点击，切换会话时卡片尺寸和位置保持稳定。

通信协议保持 **v90**，Claude Agent SDK 保持 **0.2.174**，不更换原生引擎版本。

```sh
cc-remote update --check --version 5.3.24
cc-remote update --version 5.3.24
```

从旧版升级后，独立服务器更新的首次启用与恢复操作见[应用内更新说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.24/docs/in-app-updates.md)。

## English

Match selected sessions to the device center with a soft left-edge glow, subtle border and light background tint.

- Apply the same selection treatment to compact and comfortable layouts, using each engine's theme colors.
- Soften selection backgrounds and borders while preserving session status, account labels and menu interactions.
- Keep the glow outside layout and pointer handling so selecting a session does not shift or resize its card.

Wire protocol remains **v90** and Claude Agent SDK remains **0.2.174**. Native engine versions are unchanged.

Use the update commands above. See the [in-app update guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.24/docs/in-app-updates.md) for independent server update setup and recovery.
