# cc-remote v5.3.39

## 中文

本次更新优化 DSH 终端底部操作栏，兼顾小屏手机、电脑窄侧栏和宽面板。

- 复制、粘贴、Ctrl+C 和更多菜单保持单行排列，按钮高度统一为 44px。
- 操作栏根据面板实际宽度调整，宽面板直接显示重新连接，关闭终端统一放入更多菜单。
- 连接状态移到终端选择器旁，移除重复的底部状态与说明，为终端输出保留更多空间。
- 手机键盘弹出后操作栏保持可见，中断命令时保留终端输入焦点。
- 更多菜单支持键盘导航，面板宽度变化时自动跳过隐藏操作，并保留关闭终端的确认步骤。

发布通信协议为 **v94**，Claude Agent SDK 版本为 **0.2.174**。

```sh
cc-remote update --check --version 5.3.39
cc-remote update --version 5.3.39
```

查看安装与升级步骤。[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.39/docs/installation.md)

## English

This release adapts DSH terminal controls to small phones, narrow desktop sidebars and wider panels.

- Keep copy, paste, Ctrl+C and the overflow menu on one row with consistent 44px-high buttons.
- Adapt to the panel's actual width, showing reconnect directly in wider panels and keeping terminal termination in the overflow menu.
- Move connection status beside the shell selector and remove the duplicate footer to give terminal output more space.
- Keep controls visible above the mobile keyboard and preserve terminal input focus when interrupting a command.
- Support keyboard navigation in the overflow menu, skip hidden actions after panel resizing and retain confirmation before terminating a terminal.

Wire protocol is **v94**. Claude Agent SDK version is **0.2.174**.

The commands above select this release explicitly. Follow the installation guide for setup and upgrades. [Installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.39/docs/installation_en.md)
