# cc-remote v5.3.14

## 中文

优化设备与服务端的版本差异提示，减少对聊天区域的占用。

- 协议兼容、版本号不同时，在顶部 `running / idle` 左侧显示「版本待同步」，点击查看具体版本和 `cc-remote update` 更新说明。
- 连接状态和操作反馈优先显示；协议不兼容继续保留明显横幅。
- 详情支持点击外部、Escape 和切换设备／会话时关闭。版本对齐后提示自动消失，后续出现新提示不会自动展开旧弹层。

通信协议保持 **v90**，Claude Agent SDK 保持 **0.2.174**。本次 cc-remote 更新不会替换或重启原生 DSH、Codex 或独立 Claude 会话服务。

```sh
cc-remote update --check --version 5.3.14
cc-remote update --version 5.3.14
```

更新器先验证并升级已配对的 Relay，再更新当前设备；其他设备需各自更新。更新前等待进程内会话、侧聊和排队消息完成，更新后重新加载 Web/PWA。

发布继续包含鸿蒙 **0.1.0-preview.6** 未签名 HAP、构建元数据和独立校验文件，沿用已验证的原生构建；已安装 preview.6 无需重装。HAP 需要使用自己的开发者及设备 Profile 签名。本次没有新的 Desktop 安装包。

## English

Make device/server version differences less intrusive in the conversation view.

- When protocols match but product versions differ, show a compact version-sync indicator to the left of `running / idle`. Open it to see both versions and the `cc-remote update` instructions.
- Prioritize connection and command feedback. Keep prominent banners for incompatible protocols.
- Close details on outside click, Escape or a device/session change. Clear the indicator when versions align, without automatically reopening old details when a new notice arrives.

Wire protocol **v90** and Claude Agent SDK **0.2.174** are unchanged. Updating cc-remote does not replace or restart native DSH, Codex or the independent Claude session service.

```sh
cc-remote update --check --version 5.3.14
cc-remote update --version 5.3.14
```

The updater verifies and upgrades the paired Relay before the current device. Update other devices individually, let in-process sessions, side chats and queued messages finish first, and reload Web/PWA afterwards.

Assets retain the verified HarmonyOS **0.1.0-preview.6** unsigned HAP, native-build metadata and separate checksums. Existing preview.6 users need no native reinstall; the HAP requires your own developer/device signing profile. No new Desktop installer is included.
