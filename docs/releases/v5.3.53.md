# cc-remote v5.3.53

## 中文

- 在 Codex 主会话或侧边对话里，展开后台任务即可查看启动命令和参数、工作目录与超时。
- 参数只在展开时从当前账号和会话读取。预览会遮住常见凭据，包括 Shell 命令中内嵌的 Cookie 和 Authorization 请求头。

本版使用通信协议 v97。更新步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.53/docs/installation.md)。

## English

- Expand a Codex background task in the main chat or a side chat to see its launch command and arguments, working directory, and timeout.
- Task parameters load from the current account and session on expansion. The preview masks common credentials, including Cookie and Authorization headers embedded in shell commands.

This release uses wire protocol v97. See the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.53/docs/installation_en.md) for update instructions.
