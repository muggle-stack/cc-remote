# cc-remote v5.3.56

## 中文

- Codex 处理完后台任务回调后，cc-remote 收到完成通知就更新底部计数。同一轮处理的多个回调可一起清退，仍在运行的任务继续显示。
- 迟到的列表快照和回执会按账号、会话与轮次核对，避免已确认完成的任务重新出现。

本版使用通信协议 v98。更新步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.56/docs/installation.md)。

## English

- The background task count updates when Codex finishes the corresponding callback turn. Several callbacks handled in one turn can clear together, and tasks still running stay visible.
- Delayed snapshots and receipts are checked against the matching account, session, and turn so confirmed completions stay clear of the list.

This release uses wire protocol v98. See the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.56/docs/installation_en.md) for update instructions.
