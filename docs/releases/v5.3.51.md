# cc-remote v5.3.51

## 中文

- 电脑端点一下麦克风开始实时转写，再点一下结束。手机端长按录音，松手后把转写结果留在输入框。
- 收到第一帧音频后，按钮变红并显示「正在录音」。支持震动的 Android 浏览器和鸿蒙 App 会短震一次。iPhone PWA 显示同样的录音状态。
- 鸿蒙 App 会为配置的 HTTPS 聊天页申请麦克风权限，并通过系统震动接口确认开始录音。

通信协议为 v97。语音配置见[语音输入与朗读](https://github.com/muggle-stack/cc-remote/blob/v5.3.51/docs/configuration.md#语音输入与朗读)，更新步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.51/docs/installation.md)。

## English

- Click the microphone to start and stop desktop dictation. On phones, hold to stream audio and release to keep the transcript as a draft.
- The microphone turns red and shows the recording status after the first captured audio. Supported Android browsers and the HarmonyOS app also give a short haptic cue. The same recording status is visible in iPhone PWAs.
- The HarmonyOS app requests microphone permission for the configured HTTPS chat and uses the system vibrator for recording feedback.

This release uses wire protocol v97. See the [configuration guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.51/docs/configuration.md) and [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.51/docs/installation_en.md).
