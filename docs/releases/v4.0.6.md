# cc-remote v4.0.6

## 中文

v4.0.6 修复长会话的历史展示、完成状态和重连恢复，并补齐可选的 Claude 主动额度
查询。产品版本 **4.0.6**，通信协议保持 **v72**，Claude Agent SDK 保持 **0.2.157**。

### 本次更新

- **历史与过程详情**：长回复和工具输出按需分页读取，展开过程时保留实时内容；
  侧聊、引导及重连重放保留原生消息身份和用户边界，避免内容错位、重复或缺失。
- **Claude 完成状态**：根据已消费用户输入的原生回执结束对应轮次，区分后台任务
  返回与主轮完成；旧回执、子代理结果不会错误结束当前问题。
- **会话恢复与重试**：确认旧服务已经重启且旧工作进程不再持有会话后，才能恢复
  旧会话；不重发已接受的消息。被拒绝的发送保留完整文字和附件，供用户手动重试。
- **Claude 额度**：配置账号专属的主动查询适配器后，切换会话、重连、打开额度
  面板、点击刷新及页面可见期间都会更新额度，无需发送模型消息。同账号并发查询
  合并，失败时保留有效缓存，并区分“未配置查询”与“查询失败”。
- **预览与状态**：恢复本地文件预览链接，忽略仅包含费用变化的 Claude 转录增长，
  避免无关记录触发会话状态变化。

### 升级

安装器管理的部署可在独立终端运行：

```bash
cc-remote update --version 4.0.6
```

设备更新会先检查配对 VPS；VPS 已是目标版本时只更新本机。更新后重新加载 Web/PWA。
自定义源码或容器部署继续使用原有流程，详见
[安装与升级](https://github.com/muggle-stack/cc-remote/blob/v4.0.6/docs/installation.md)。

本次 Claude 完成回执修复包含独立会话服务的改动。普通 Wrapper 更新会保留已有服务
及其任务；按[Claude 服务指南](https://github.com/muggle-stack/cc-remote/blob/v4.0.6/docs/claude-session-service.md)
等待原生轮次、后台工作及回调结束后更新该服务。只更新 Wrapper 不会让旧服务获得
新的完成回执能力，不要为清除运行状态而中断任务或重发已接受的消息。

主动额度查询需要在仓库外配置由运营者维护的适配器，账号凭据由提供方或登录工具
保管；发布包不包含提供方专用代码或凭据。未配置时仍通过原生额度事件同步。
配置方式见[Claude 额度查询](https://github.com/muggle-stack/cc-remote/blob/v4.0.6/docs/claude-usage.md)。

从 v4.0.3 或更早版本升级，还需遵循
[v4.0.4 的 SDK 迁移要求](https://github.com/muggle-stack/cc-remote/blob/v4.0.6/docs/releases/v4.0.4.md#升级)。

本次发布 Web、Relay 和 Claude/Codex Wrapper，通信协议保持 v72。

## English

v4.0.6 repairs long-session history, completion state and reconnect recovery,
and adds optional active Claude quota reads. Product version **4.0.6**, wire
protocol **v72**, Claude Agent SDK **0.2.157**.

- **History and process details:** page long responses and tool output on demand
  while retaining live content. Preserve native message identities and user
  boundaries across side chats, steering and replay.
- **Claude completion:** match terminal receipts to consumed human input while
  keeping background continuations distinct. Stale receipts and child results
  cannot finish the current human query.
- **Recovery and retry:** recover an old session only after proving that its
  service restarted and no old worker owns the transcript. Never replay accepted
  queries; retain rejected text and attachments for manual retry.
- **Claude quota:** with an account-scoped usage helper configured, refresh on
  focus, reconnect, meter open/manual refresh and visible-page polling without
  sending a model prompt. Coalesce reads per account, preserve valid cached
  observations on failure and distinguish missing configuration from read errors.
- **Previews and state:** restore local file preview links and ignore cost-only
  Claude transcript growth when observing session activity.

### Upgrade

For installer-managed deployments, run `cc-remote update --version 4.0.6` in an
independent terminal, then reload Web/PWA. Device updates verify the paired Relay
first and skip it if already current. Custom source and container deployments
keep their existing procedures; see the
[installation guide](https://github.com/muggle-stack/cc-remote/blob/v4.0.6/docs/installation_en.md).

The Claude terminal-receipt fix changes the independent session service. An
ordinary Wrapper upgrade preserves that service and its tasks. Follow the
[Claude service guide](https://github.com/muggle-stack/cc-remote/blob/v4.0.6/docs/claude-session-service.md)
after native turns, background work and callbacks drain. A Wrapper-only upgrade
cannot add the capability to an old service; do not interrupt work or replay
accepted input to clear a running indicator.

Active quota reads require an operator-owned helper configured outside the
repository. The provider or login tool retains account credentials; release
bundles contain no provider-specific adapter or credentials. Without a helper,
native quota events continue to work. See the
[Claude quota guide](https://github.com/muggle-stack/cc-remote/blob/v4.0.6/docs/claude-usage.md).

Upgrades from v4.0.3 or earlier must also follow the
[v4.0.4 SDK migration requirements](https://github.com/muggle-stack/cc-remote/blob/v4.0.6/docs/releases/v4.0.4.md#upgrade).

This release contains Web, Relay and Claude/Codex Wrappers, with wire protocol v72.
