# cc-remote v5.3.27

## 中文

本次更新优化设备切换恢复、通知跳转和 Claude 模型回退交互。

- 切回已访问的设备时立即恢复对应会话的缓存画面，在后台核对最新会话目录和历史，并恢复原生会话连接。
- 点击系统通知时重新验证目标设备，重试短暂连接故障并去重重复事件。验证失败后可重新尝试，已在当前会话时保留当前阅读状态。
- 生成图片的加载提示单行居中显示。
- Claude 模型回退确认支持同意、拒绝、编辑原提问和收起后继续处理，备用模型动态采用 CLI 提供的目标。未设置自动切换偏好时默认询问，明确选择后按账号保存自动切换偏好。
- 实时更新现有模型选择器显示的实际模型，重连后恢复回退提醒和可用的原生切换时间。
- 桌面和手机共用待确认问题生命周期，保留收起状态和选择，等待原生确认后关闭。

发布协议为 **v93**，Claude Agent SDK 版本为 **0.2.174**。Relay、Web 和 Wrapper 需使用同一版本协调升级。

Claude 原生回退确认能力在进程初始化时声明。现有服务的任务、待回答问题及后台工作全部结束后，按会话服务说明升级独立服务，由新版服务创建原生进程以启用确认能力。[Claude 会话服务说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.27/docs/claude-session-service.md)

```sh
cc-remote update --check --version 5.3.27
cc-remote update --version 5.3.27
```

查看完整安装与升级步骤。[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.27/docs/installation.md)

## English

This update improves device restoration, notification navigation and Claude model-fallback interaction.

- Restore the cached view immediately when returning to a visited device, validate its current session catalog and history in the background, and reconnect the native session.
- Revalidate notification destinations, retry transient connectivity failures and deduplicate delivery. Permit retry after failed validation and retain the current reading position when the target is already focused.
- Center generated-image loading text on one line.
- Support native Claude fallback agreement, rejection, original-prompt editing and collapsible pending confirmation. Use the fallback model supplied by the CLI. An unset automatic-switch preference defaults to asking, and an explicit automatic-switch choice is saved for that account.
- Update the existing model selector with the applied model in real time and recover fallback warnings and available native switch times after reconnect.
- Preserve pending-question state and selections across desktop and mobile until the native interaction closes.

Wire protocol is **v93**. Claude Agent SDK version is **0.2.174**. Upgrade Relay, Web and Wrapper together from the same version.

Native fallback confirmation is negotiated at worker initialization. Drain the existing tasks, pending questions and background work, then upgrade the independent Claude session service and enable confirmation with workers created by the updated service. Follow the session-service upgrade procedure. [Claude session-service guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.27/docs/claude-session-service.md)

Use the update commands above and follow the installation guide for setup and upgrades. [Installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.27/docs/installation_en.md)
