# cc-remote v5.3.21

## 中文

统一常用面板样式，并修复刷新页面后终端状态按钮突然出现、挤动空闲／运行标签的问题。

- 设备中心、文件、Artifacts 和页面预览采用统一的纯图标刷新与收起控件。刷新时显示加载动画，成功后短暂显示完成反馈，按钮尺寸保持不变。
- 当前设备使用左侧光边标识；配对界面突出可复制的终端命令，并显示剩余有效时间。设备与预览行的操作收进支持键盘导航的菜单。
- Artifacts 支持按图片、文档和其他文件筛选已加载内容，显示大小与来源；文件浏览增加项目数量提示。
- 终端状态与使用活动面板采用更简洁的布局，使用活动保留打开时自动更新。
- 状态栏使用等宽的「空闲／运行」中文标签，保留运行呼吸灯。终端图标随顶部控件一起显示，会话尚未就绪时置灰，恢复后原位更新。

通信协议保持 **v90**，Claude Agent SDK 保持 **0.2.174**。本次更新不更换原生引擎版本。

已启用应用内更新的设备，可从右上角「⋮ → 检查更新」进入并安装。也可使用：

```sh
cc-remote update --check --version 5.3.21
cc-remote update --version 5.3.21
```

首次启用与恢复操作见[应用内更新说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.21/docs/in-app-updates.md)。

## English

Unify frequently used panels and prevent the terminal status button from shifting the idle/running badge after a page refresh.

- Share icon-only refresh and close controls across devices, files, artifacts and previews. Loading and brief success feedback keep the button dimensions stable.
- Highlight the current device along its left edge. Emphasize the pairing command with copy feedback and an expiry countdown; provide keyboard navigation for device and preview row menus.
- Filter loaded artifacts by image, document or other file, with size and source metadata. Show the number of loaded entries in the file browser.
- Simplify terminal status and usage activity layouts while retaining usage refresh on opening.
- Use compact, fixed-width Chinese idle/running labels with the running indicator. Render a disabled terminal icon with the header until a session is ready, then update it in place.

Wire protocol remains **v90** and Claude Agent SDK remains **0.2.174**. Native engine versions are unchanged.

Devices with in-app updates enabled can use **⋮ → Check for updates**, or run the commands above. See the [in-app update guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.21/docs/in-app-updates.md) for setup and recovery.
