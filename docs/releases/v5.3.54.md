# cc-remote v5.3.54

## 中文

- HTML 远程预览自动适应面板宽度，窄栏也能看全页面，刷新后保留缩放设置。
- PDF 支持缩放、选字和跨页搜索。手机上滑动 PPTX 时，页码与画面同步。
- 文件预览支持 DOCX、WebM 视频，以及 HEIC、TIFF 和 BMP 图片。表格支持分页，保留常用 Excel 日期和百分比显示。
- CSV 和 TSV 的长单元格会截短显示，后续行列照常显示。原件下载保留原始文件字节。

本版使用通信协议 v98。Relay、Web 和 Wrapper 需使用兼容版本。更新步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.54/docs/installation.md)。

## English

- Remote HTML previews fit narrow panels and keep the selected zoom after refresh.
- PDF previews support zoom, text selection, and search across pages. PPTX slide numbers stay in sync when swiping on mobile.
- File previews support DOCX, WebM video, and HEIC, TIFF, and BMP images. Spreadsheet previews paginate rows and display common Excel date and percentage formats.
- Long CSV and TSV cells are shortened for display, and subsequent rows and columns stay visible. Downloads preserve the original file bytes.

This release uses wire protocol v98. Use compatible versions of Relay, Web, and Wrapper. See the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.54/docs/installation_en.md) for update instructions.
