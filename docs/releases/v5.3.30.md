# cc-remote v5.3.30

## 中文

本次更新修复设备切换后的会话归属、运行中会话的阅读恢复，并优化 Codex 异步回答的提交交互。

- 聊天连接显式绑定目标设备，并等待已授权设备列表就绪，修复选择 Default 后显示其他设备会话内容的问题。
- 在 Claude、Codex、DSH 之间切换后恢复阅读位置，继续实时更新工具过程、处理状态和小火花。向下滑到底后恢复自动跟随。
- 恢复阅读位置时等待对应消息行完成挂载，历史分页与已移出实时窗口的阅读位置可通过保存的页面恢复。
- Codex 异步回答提交后立即收起弹窗，后台确认送达，发送失败可恢复草稿。
- 自定义回答输入框聚焦时清除选项高亮，首次展示时默认选中第一项。

发布通信协议为 **v94**，Claude Agent SDK 版本为 **0.2.174**。Relay 与 Web 配套升级，Wrapper 通过独立维护通道逐台升级。

```sh
cc-remote update --check --version 5.3.30
cc-remote update --version 5.3.30
```

查看安装与升级步骤。[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.30/docs/installation.md)

## English

This update repairs device selection and live reading restoration and improves Codex asynchronous question submission.

- Bind chat connections to the selected device after authorized device discovery, fixing other-device content appearing when Default is selected.
- Restore the reading position when switching between Claude, Codex and DSH while updating tools, processing status and working marks. Scrolling to the bottom resumes following live output.
- Wait for the bookmarked message row to mount during restoration. Retain saved pages for historical reading and live rows that leave the current window.
- Close Codex question dialogs immediately after submission, confirm delivery in the background and retain drafts for failed submissions.
- Clear the selected option when the custom answer gains focus, with the first option selected on initial display.

Wire protocol is **v94**. Claude Agent SDK version is **0.2.174**. Upgrade Relay and Web together, then upgrade Wrappers individually through maintenance.

The commands above select this release explicitly. Follow the installation guide for setup and upgrades. [Installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.30/docs/installation_en.md)
