# cc-remote v5.3.20

## 中文

修复应用内更新中断后卡住、会话无法继续，以及长任务历史中的重复文字和消息遗漏。

- 终端与 UI 更新共用原事务恢复。SSH 确认丢失、更新控制进程或安装进程退出后，继续核对原任务；需要回滚时恢复匹配的配置和私有数据，不重复提交安装。
- 修复旧版 Wrapper 不认识新检查指令导致回滚无法完成、同版本重装已恢复却仍限制会话，以及直接重跑安装脚本覆盖未完成事务记录的问题。
- 对临时 TLS、下载和 SSH 故障进行有限重试；证书、认证和协议问题分别报告。登录重连时保留新会话草稿。
- 修复 Codex 长任务中开头段落反复显示、后台任务返回时用户消息被错误合并，以及只请求一条历史时加载越界的问题。
- 修复 Claude 首轮只有工具输出时未及时记录会话身份，以及重连后待回答问题的路由恢复。

已确认独立运行且可恢复的原生任务可以继续执行。Wrapper 内的排队消息、私有任务、临时附件依赖及其他不能安全迁移的操作仍需等待安全边界；普通更新不重启独立 Claude 服务。

通信协议保持 **v90**，Claude Agent SDK 保持 **0.2.174**。本次更新不更换原生引擎版本。

已启用应用内更新的设备，可从右上角「⋮ → 检查更新」进入并安装。也可使用：

```sh
cc-remote update --check --version 5.3.20
cc-remote update --version 5.3.20
```

首次启用与恢复操作见[应用内更新说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.20/docs/in-app-updates.md)。设备需要能够访问 GitHub，协议或 SDK／服务契约变化仍需协调维护。

## English

Recover interrupted in-app updates and repair repeated or missing messages in long-running conversation history.

- CLI and UI updates share recovery of the original transaction after a lost SSH acknowledgement, controller exit or installer termination. Rollback restores the matching configuration and private state without submitting another installation.
- Fix rollback health checks for previous Wrappers, recovery of healthy same-release reinstalls, and direct installer retries overwriting unfinished activation records.
- Bound retries for transient TLS, download and SSH failures; report certificate, authentication and protocol problems separately. Preserve new-chat drafts across authentication reconnects.
- Fix repeated opening paragraphs during long Codex tasks, human messages incorrectly merged with background callbacks, and out-of-bounds hydration for one-row history requests.
- Capture Claude session identity on a tool-only first response and restore pending question routes after reconnecting.

Confirmed independent, recoverable native tasks can continue. Wrapper-owned queues, private tasks, temporary attachment dependencies and other operations that cannot safely migrate still wait for a safe boundary. Ordinary updates preserve the independent Claude service.

Wire protocol **v90** and Claude Agent SDK **0.2.174** are unchanged. This release does not upgrade native engines.

On devices with in-app updates enabled, open **⋮ → Check for updates** to install, or run:

```sh
cc-remote update --check --version 5.3.20
cc-remote update --version 5.3.20
```

See the [in-app update guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.20/docs/in-app-updates.md) for setup and recovery. Devices need GitHub connectivity; protocol or SDK/service-contract changes still require coordinated maintenance.
