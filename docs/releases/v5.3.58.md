# cc-remote v5.3.58

## 中文

- 普通发送通过空闲检查后，如果 Codex 后台回执抢先开启回合，原消息和附件会送入已确认的回执回合。
- 回执已结束时，CC Remote 会向 app-server 核对会话状态，确认空闲后开启新回合。
- 发送结果不明时，Web 保留原消息，按消息 ID 等待确认，避免重复提交。

本版使用通信协议 v98。更新步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.58/docs/installation.md)。

## English

- If a Codex background receipt opens a turn after a direct send has passed the idle check, CC Remote sends the original message and attachments into the confirmed receipt turn.
- If the receipt turn has already finished, CC Remote checks with app-server and opens a new turn once the thread is idle.
- When delivery is uncertain, Web keeps the original message and waits for confirmation by message ID to avoid duplicate submission.

This release uses wire protocol v98. See the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.58/docs/installation_en.md) for update instructions.
