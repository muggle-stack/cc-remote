# cc-remote v5.3.7

## 中文

修复动态 SVG 预览，支持空闲 Claude 会话交还本地终端，并恢复每个 Release 的鸿蒙安装包。

- SVG 预览保留声明式动画、本地引用，以及渐变和图案的变换动画；脚本和外部资源仍受原有安全限制。
- 本地 Claude 进程可申请释放 Remote 持有的空闲会话。释放必须确认原生进程已经退出，忙碌或退出未确认时不会允许接手。
- 发布流程必须附带已校验的鸿蒙未签名 HAP、`MOBILE_BUILD_INFO.json` 和 `MOBILE_SHA256SUMS`。原生源码或构建输入发生变化后，必须提供新构建才能发布。

通信协议保持 **v85**，Claude Agent SDK 保持 **0.2.174**。从 v5.3.6 升级无需协议或 SDK 迁移。更新 Relay 和各台 Wrapper 后刷新 Web/PWA 或重新打开 Desktop。

```sh
cc-remote update --check --version 5.3.7
cc-remote update --version 5.3.7
```

普通 Wrapper 更新保留独立 Claude 会话服务；仍在 Wrapper 内运行的侧聊及排队消息需先完成。发布包含六个平台的 Relay/Wrapper 包、`install.sh`、`SHA256SUMS` 及上述鸿蒙附件，没有新的 Desktop 安装包。鸿蒙包保留真实原生版本 **0.1.0-preview.5**，需要自行签名；已有相同原生版本的用户无需重装。

## English

Repair animated SVG previews, support local handoff of idle Claude sessions, and restore a HarmonyOS package in every release.

- Preserve declarative SVG animations, local references, and gradient/pattern transforms. Scripts and external resources remain subject to the existing preview security boundary.
- Allow a local Claude process to request release of an idle session held by Remote. Handoff requires confirmed native process exit; busy or unconfirmed releases are rejected.
- Require a validated unsigned HarmonyOS HAP, `MOBILE_BUILD_INFO.json` and `MOBILE_SHA256SUMS` before publishing. Native source or build-input changes require a newly validated build.

Wire protocol remains **v85** and Claude Agent SDK remains **0.2.174**. Upgrading from v5.3.6 needs no protocol or SDK migration. Update the Relay and each Wrapper, then reload Web/PWA or reopen Desktop.

```sh
cc-remote update --check --version 5.3.7
cc-remote update --version 5.3.7
```

Ordinary Wrapper updates preserve the independent Claude session service. In-process side chats and queued messages must finish before activation. The release includes six platform-specific Relay/Wrapper bundles, `install.sh`, `SHA256SUMS` and the HarmonyOS assets above, with no new Desktop installer. The HarmonyOS package retains its actual native version, **0.1.0-preview.5**, and requires signing. Users already running the same native version do not need to reinstall it.
