# cc-remote v5.3.16

## 中文

修复更新期间的会话恢复，并简化应用更新窗口。

- 更新过程中重新登录时，在顶部显示更新进度，避免误报「当前操作暂时无法执行」。确认设备就绪后，只恢复当前查看的会话。
- 维护期间仍可浏览历史，草稿和附件继续保留。被维护状态拒绝的消息可手动重试，不会自动重新发送。
- 打开「应用更新」窗口即自动检测，包括打开时已有状态查询正在进行的情况。版本摘要、安装进度和页面刷新提示分开显示，详细更新记录可展开查看；移除手动检测按钮和旧版本备份提示。
- 移除手机点击链接、按钮及展开项时的默认青色色块，使用应用主题内的反馈，保留键盘焦点样式。

通信协议保持 **v90**，Claude Agent SDK 保持 **0.2.174**。本次更新不更换原生引擎版本。

已启用应用内更新的设备，可从右上角「⋮ → 检查更新」进入并安装。也可使用：

```sh
cc-remote update --check --version 5.3.16
cc-remote update --version 5.3.16
```

首次启用条件见[应用内更新说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.16/docs/in-app-updates.md)。设备需要能够访问 GitHub；已知代理 TLS 失败仍可能被显示为「协议变化」，本次未调整该错误分类。

## English

Fix session recovery during application updates and simplify the update dialog.

- Show update progress in the header when signing in during maintenance instead of a generic operation-failed warning. Recover only the currently viewed session after device readiness is confirmed.
- Keep history readable and retain drafts and attachments during maintenance. Rejected messages remain available for manual retry and are not automatically resent.
- Check automatically whenever the update dialog opens, including when a status request is already in flight. Separate version summaries, installation progress and page-refresh prompts; keep full release notes expandable. Remove manual check controls and backup-retention notices.
- Suppress native cyan tap overlays on mobile buttons, links and disclosures. Use themed interaction feedback and retain keyboard focus indicators.

Wire protocol **v90** and Claude Agent SDK **0.2.174** are unchanged. This release does not upgrade native engines.

On devices with in-app updates enabled, open **⋮ → Check for updates** to install, or run:

```sh
cc-remote update --check --version 5.3.16
cc-remote update --version 5.3.16
```

See the [in-app update guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.16/docs/in-app-updates.md) for first-time setup. Devices need GitHub connectivity; the existing misclassification of some proxy TLS failures as a protocol change remains unchanged.
