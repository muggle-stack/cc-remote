# cc-remote v5.3.31

## 中文

本次更新修复清理器对服务时区配置的误判，避免升级成功后旧部署文件清理被错误延期。

- 正确识别 `TZ=America/Los_Angeles` 等地理时区、POSIX 时区规则及带冒号的时区文件引用，覆盖 systemd 环境文件、内联环境变量和 launchd 配置。
- 将真实时区文件、`TZDIR` 目录、zoneinfo 符号链接及 `posixrules` 纳入保留依赖，空 `TZDIR` 使用系统时区目录。
- 清理过程中重新检查依赖，发现新增时区引用时恢复已隔离的旧版本。
- 无法解析的相对或动态 `TZDIR`，以及通过 `PassEnvironment` 继承的时区设置，要求显式保留清单。

发布通信协议为 **v94**，Claude Agent SDK 版本为 **0.2.174**。Relay 与 Web 配套升级，Wrapper 通过独立维护通道逐台升级。

```sh
cc-remote update --check --version 5.3.31
cc-remote update --version 5.3.31
```

查看安装与升级步骤。[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.31/docs/installation.md)

## English

This update fixes service timezone parsing that could defer old deployment cleanup after a successful upgrade.

- Recognize geographic zones such as `TZ=America/Los_Angeles`, POSIX timezone rules and colon-prefixed timezone file references in systemd environment files, inline variables and launchd configuration.
- Protect actual timezone files, `TZDIR` directories, zoneinfo aliases and `posixrules`. An empty `TZDIR` uses the system timezone directory.
- Recheck dependencies during cleanup and restore quarantined generations when a new timezone reference appears.
- Require an explicit retention inventory for unresolved relative or dynamic `TZDIR` values and timezone settings inherited through `PassEnvironment`.

Wire protocol is **v94**. Claude Agent SDK version is **0.2.174**. Upgrade Relay and Web together, then upgrade Wrappers individually through maintenance.

The commands above select this release explicitly. Follow the installation guide for setup and upgrades. [Installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.31/docs/installation_en.md)
