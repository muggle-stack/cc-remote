# cc-remote v5.3.62

## 中文

- Codex 临时侧边聊天已无活动回合且无法核对回执时，应用更新可继续。已完成的任务结果和退出码会保留。
- 应用更新窗口会列出正在等待的操作和相关会话。

本版使用通信协议 v98。更新步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.62/docs/installation.md)。

## English

- Allow device updates to proceed when an accepted Codex side-chat callback cannot be confirmed and the temporary thread is inactive. Keep the completed task result and exit code.
- List the operations and conversations holding up device updates in the update window.

This release uses wire protocol v98. See the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.62/docs/installation_en.md) for update instructions.
