# cc-remote v5.3.40

## 中文

本次更新完善 DSH 移动端终端手势和键盘控制，并缩小普通聊天输入区在键盘展开时的底部留白。

- 直接滑动浏览终端输出，长按拖动发送四向按键，并按拖动距离提供三档连发速度。
- 长按后松手选择文字，可拖动两侧手柄调整选区，使用复制、粘贴、全选和取消选择菜单。
- 双击终端发送 Tab，手机底部提供单行可横向滚动的快捷键栏及键盘开关。
- 收起键盘后，滚动、粘贴、连接恢复及面板切换遵循关闭状态，系统返回键收起键盘也会同步。
- 按终端实际位置对齐选区手柄，避免横向拖动时误选下一行。桌面继续支持触控板滚动、鼠标选择和全屏程序输入。
- 普通聊天输入区在软键盘展开时释放重复预留的底部安全区，键盘关闭后恢复。

iOS 键盘的灰色上下箭头／完成栏由系统控制。真实手机的软键盘交互仍待设备验收。

发布通信协议为 **v94**，Claude Agent SDK 版本为 **0.2.174**。

```sh
cc-remote update --check --version 5.3.40
cc-remote update --version 5.3.40
```

查看安装与升级步骤。[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.40/docs/installation.md)

## English

This release improves DSH mobile terminal gestures and keyboard control, and reduces the chat composer's bottom spacing while the software keyboard is open.

- Swipe to browse terminal output. Hold and drag to send arrow keys with three repeat speeds based on drag distance.
- Release a stationary long press to select text, adjust the range with handles, and use the copy, paste, select-all and clear-selection menu.
- Double-tap to send Tab and use a single horizontally scrollable shortcut row with an explicit keyboard toggle.
- Preserve keyboard dismissal through scrolling, pasting, connection recovery and panel switches, including dismissal through the system Back button.
- Align selection handles with the actual terminal viewport to prevent horizontal drags from selecting another line. Preserve desktop trackpad scrolling, mouse selection and full-screen application input.
- Remove duplicate bottom safe-area spacing while the chat software keyboard is open and restore it when the keyboard closes.

The gray previous/next/done keyboard accessory on iOS remains system-controlled. Physical-device software keyboard acceptance is still pending.

Wire protocol is **v94**. Claude Agent SDK version is **0.2.174**.

The commands above select this release explicitly. Follow the installation guide for setup and upgrades. [Installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.40/docs/installation_en.md)
