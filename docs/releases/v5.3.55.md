# cc-remote v5.3.55

## 中文

- Bridge 远程预览通过现有授权通道加载脚本设置的本地图片，修复图片空白及 `img-src` 提示。
- 传输期间图片保持加载中状态，页面可在 `load` 事件后读取正确尺寸。读取失败时提示具体资源路径。

本版使用通信协议 v98。更新步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.55/docs/installation.md)。

## English

- Bridge previews use the existing authorized resource channel for local images assigned by scripts, fixing blank images and `img-src` warnings.
- Images stay pending during transfer so pages can read their dimensions after the `load` event. Read failures identify the affected resource path.

This release uses wire protocol v98. See the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.55/docs/installation_en.md) for update instructions.
