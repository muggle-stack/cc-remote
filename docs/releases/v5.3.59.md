# cc-remote v5.3.59

## 中文

- 聊天中的 Markdown 尖括号文件链接即使在绝对路径前多写了空格，也能正常打开预览。重新打开旧消息时同样生效。
- 文件名中实际存在的空格和显式编码的空格照常保留。

本版使用通信协议 v98。更新步骤见[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.59/docs/installation.md)。

## English

- Chat previews open local file links when a Markdown angle-bracket destination has extra spaces before its absolute path. Saved replies get the same behavior when rendered.
- Spaces within filenames and explicitly encoded spaces are preserved.

This release uses wire protocol v98. See the [installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.59/docs/installation_en.md) for update instructions.
