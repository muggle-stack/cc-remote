# cc-remote v5.3.28

## 中文

本次更新优化托管安装的升级、下载恢复与取消处理。

- 更高版本的正式 Release 支持跨聊天协议升级，服务器和设备可以通过独立维护通道分别更新，离线设备上线后执行已确认的更新请求。
- 下载中断后保存进度，网络恢复后退避重试并续传。支持 HTTP Range 和 ETag，服务器忽略续传请求或文件内容变化时重新下载，完整安装包校验 SHA-256。
- 重试复用同一份下载缓存，缓存上限为 512 MiB、8 项，24 小时过期。成功或取消后回收对应缓存，异常退出的解压目录按进程身份核对后清理。
- 系统更新任务消失或结束后，释放本次下载的挂起状态，保留有效缓存供重新更新。已退出的下载任务可以立即取消，延迟启动的旧进程读取持久化取消结果。
- Relay 持续保存取消意图，未确认的取消请求随状态轮询或重连补发。设备返回最终结果后结束跟踪。
- 桌面和手机显示等待网络、等待设备上线及取消状态，页面重开后继续跟踪原任务。

发布协议为 **v93**，Claude Agent SDK 版本为 **0.2.174**。Relay 与 Web 成组激活，Wrapper 通过维护通道逐台升级。

已安装的旧更新器继续执行其原有协议检查。首次跨协议过渡时，可在独立终端为更新命令指定 `--allow-protocol-change`，或运行已校验的新 Release `install.sh`。完成一次过渡后，后续升级使用新版恢复流程。

```sh
cc-remote update --check --version 5.3.28
cc-remote update --version 5.3.28 --allow-protocol-change
```

Claude 会话服务升级遵循现有迁移流程。[Claude 会话服务说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.28/docs/claude-session-service.md)

查看完整安装与升级步骤。[安装说明](https://github.com/muggle-stack/cc-remote/blob/v5.3.28/docs/installation.md)

## English

This update improves managed upgrades, download recovery and cancellation handling.

- Upgrade newer stable releases across chat-protocol versions through the independent maintenance channel. Server and device upgrades proceed independently, and offline devices retain confirmed update requests for delivery when they reconnect.
- Preserve interrupted downloads, retry transient outages with backoff and resume with HTTP Range and ETag. Restart downloads when Range is ignored or the entity changes, then verify the complete archive with SHA-256.
- Reuse the same download cache across retries, bounded to 512 MiB, eight entries and 24 hours. Success and cancellation retire their cached bytes, and abandoned extraction directories are reclaimed after checking their process identity.
- Settle pending downloads when their OS update job has disappeared or ended, retaining valid cached bytes for a fresh attempt. Cancel departed download workers immediately and fence delayed restarts with a durable cancellation receipt.
- Preserve Relay cancellation intent through status polling and reconnects, retrying delivery until acknowledged. A terminal device receipt settles the request.
- Show network, device and cancellation waiting states on desktop and mobile, and recover the original task after reopening the page.

Wire protocol is **v93**. Claude Agent SDK version is **0.2.174**. Activate Relay and Web together, then upgrade Wrappers individually through maintenance.

Installed older updaters retain their original protocol checks. For the first cross-protocol transition, use `--allow-protocol-change` from an independent terminal or run the verified new Release's `install.sh`. Subsequent upgrades use the new recovery flow. The commands above select this release explicitly.

Follow the existing migration procedure when upgrading the independent Claude session service. [Claude session-service guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.28/docs/claude-session-service.md)

Follow the installation guide for setup and upgrades. [Installation guide](https://github.com/muggle-stack/cc-remote/blob/v5.3.28/docs/installation_en.md)
